## Що це

Етикетка будь-якого товару — антени, фільтра чи іншого — складається з **одного макета**. Змінюється лише
текст:

```text
P/N: AN220214-01A                      Sevskiy GmbH
QTY: 5 PCS                [штрихкод AN220214-01A]
[QR AN220214-01A]  Digi-Key P/N: 3228-AN220214-01A-ND.
                   Omni antenna 2.4/5.8 GHz, 3 dBi, IP67.
                   Frequency range: 2.4...5.9 GHz.
                   Connector type: SMA male.
                   Copyright © 2009 - 2026 Sevskiy GmbH.
                   All rights reserved. Reproduction prohibited.
```

- **P/N, штрихкод, QR** — артикул з рядка замовлення (саме той, що замовили; у замовленні DigiKey це може бути
  Supplier SKU, відмінний від артикула в картці товару);
- **QTY** — кількість з рядка замовлення (або з поля кількості біля кнопки);
- **рядки над Copyright** — Digi-Key P/N, опис, частота, роз'єм: разом **не більше 4 рядків**, кожен **до 46 символів**
  (довше DYMO обріже);
- **рік** у Copyright — поточний, ставиться сам.

Файл етикетки при цьому не зберігається — щоразу складається заново з актуальних даних. Старі `.dymo`-файли в
базі не змінюються, лише читаються.

## Звідки Minerva бере тексти

Для **опису**, **частоти** й **роз'єму** береться перше непорожнє:

1. **✋ перевірено раніше** — те, що людина підтвердила у вікні перевірки для цього артикула;
2. далі за налаштуванням **«Етикетка з шаблону: звідки брати опис, частоту, роз'єм»** ([Налаштування
   етикеток](guide:labels/settings)), за замовчуванням:
   - **📦 склад** — опис: **«Назва (EN/DE) для документів»**, інакше назва товару (лише латиницею й не номер на
     кшталт `3228-…-ND`); частота й роз'єм — **«Технічні атрибути»** товару (Frequency Range, Pass Band…,
     Termination, Connector Type);
   - **🔷 DigiKey** — назва й параметри [лістингу DigiKey](guide:digikey/listings);
   - **📄 старий файл** — тексти наявної `.dymo`-етикетки цього артикула.

Якщо товар знайдено лише за Supplier SKU DigiKey іншого товару, першою йде стара етикетка саме цього артикула.

Частота з DigiKey приводиться до одних одиниць: `600MHz ~ 7.2GHz` → `0.600...7.2 GHz`.

### Що відрізняється за видом товару

| | Антена | Фільтр | Інший товар |
|---|---|---|---|
| Рядків опису | до 2 | до 2 | до 3 |
| Підпис частоти | «Frequency range:» (діапазон) / «Frequency:» | «Pass band:» або «Stop band:» (за типом фільтра) | як в антени |
| Порожня частота | ⚠️ попередження | ⚠️ попередження | мовчки |
| Порожній роз'єм | ⚠️ попередження | ✓ примітка | мовчки |

### Digi-Key P/N

Номер DigiKey складається сам: числовий Vendor ID + Supplier SKU лістингу + `-ND` (`3228-AN220214-01A-ND`) —
лише для опублікованого лістингу DigiKey. За замовчуванням рядок друкується на замовленнях DigiKey; у вікні
перевірки — галочка біля поля **«Digi-Key P/N»**, саме поле можна виправити.

## Вікно перевірки

Відкривається само, коли щось треба перевірити (перший друк артикула, змінились дані, є зауваження — залежить
від налаштування **«…коли показувати вікно перевірки»**). Відкрити завжди: правий клік на 🖨️ →
**«🔍 Перевірити дані етикетки…»**, або 🧩 на сторінці [🏷️ Наклейки DYMO](/labels/).

Що у вікні **«🏷️ Етикетка антени · AN220214-01A»** (фільтра, товару):

1. **Макет етикетки** — як вона виглядатиме; дані, що змінюються, підсвічено помаранчевим.
2. Поля: **«Кількість»**, **«Digi-Key P/N»** (з галочкою «друкувати»), **«Опис»**, **«Частота»** (у фільтра —
   **«Смуга (Pass / Stop band)»**), **«Роз'єм»**, **«Рік»**. Під кожним — **«Зараз: 📦 склад»** (звідки значення) і
   чипи з варіантами з інших джерел: **«🔷 DigiKey: …»**, **«📄 старий файл: …»**, **«✋ перевірено раніше: …»**.
   Клік на чип — підставити. Можна й просто вписати свій текст — макет оновиться.
3. **Зауваження**: ⛔ помилка (друк заблоковано), ⚠️ попередження, ✓ примітка. Немає жодного —
   **«✓ Артикул, кількість і рік перевірено — зауважень немає.»**
4. Кнопки: **«🖨️ Друкувати»**, **«⬇️ Завантажити .dymo»**, **«📄 Старий файл»** (наявний файл як є, без змін),
   **«Скасувати»**. Посилання **«⚙️ За замовчуванням»** — на налаштування.

Після **«🖨️ Друкувати»** чи **«⬇️ Завантажити .dymo»** тексти **запам'ятовуються для артикула** (хто й коли
перевіряв — під кнопками). Наступні кліки друкують одразу, без вікна, поки дані на складі чи DigiKey не
зміняться — тоді вікно покаже **«… тепер «…» (під час перевірки було «…») — перевірте.»**

## Приклади

**Антена з DigiKey-замовлення.** Замовили `AN220214-01A` × 5. Клік **«🖨️ Друкувати (5 шт.)»** у картці
замовлення → перший раз вікно: опис зі складу, частота з DigiKey, Digi-Key P/N з галочкою. Зауваження «⚠️ Частота:
📦 склад «2.4...5.8 GHz», а 🔷 DigiKey «2.4...5.9 GHz» — перевірте» → клік на правильний чип → **«🖨️ Друкувати»**.
Наступного разу — друк одразу.

**Фільтр без роз'єму.** `FT220407`: частота з атрибута Pass Band → рядок «Pass band: 2700...3650 MHz.»; роз'єму
немає — лише примітка, друк не блокується.

## Що означають зауваження

| Зауваження | Що робити |
|---|---|
| **«Немає опису: ні на складі, ні на DigiKey, ні в старому файлі — впишіть.»** | впишіть опис у поле або заповніть «Назва (EN/DE) для документів» у товарі |
| **«Опис займає 3 рядки — вміщується 2. Скоротіть.»** | скоротіть опис |
| **«Над Copyright 5 рядків — вміщується 4…»** | скоротіть опис до одного рядка або зніміть галочку Digi-Key P/N |
| **«Рядок «…» довший за 46 символів — DYMO обріже кінець.»** | скоротіть текст |
| **«Немає частоти — рядок «Frequency range» не друкується.»** | впишіть частоту або заповніть технічні атрибути товару |
| **«Digi-Key P/N не друкується: лістинг DigiKey ще не опубліковано.»** | опублікуйте лістинг або впишіть номер вручну |
| **«…невідомий числовий Vendor ID DigiKey (як 3228) — впишіть Digi-Key P/N.»** | впишіть номер у поле |
| **«Товару … немає на складі — дані лише зі старого файлу.»** | перевірте артикул або додайте товар |
| **«У старому файлі … рік 2023 — на новій етикетці 2026.»** | лише інформація: стара етикетка мала помилку, нова — правильна |
| **«Файл … має інший макет — його можна надрукувати як є («📄 Старий файл»).»** | друкуйте шаблон або старий файл кнопкою |

## Часті питання та проблеми

**Хочу надрукувати саме старий файл** — у вікні **«📄 Старий файл»**, або правий клік на 🖨️ → **«📄 Завантажити з
бази»** / **«🖨️ Друкувати файл з бази на DYMO…»**.

**Виправив опис у товарі, а друкує старий текст** — для артикула є перевірений текст (✋), він має перевагу.
Правий клік → **«🔍 Перевірити дані етикетки…»** → клік на чип **«📦 склад»** → **«🖨️ Друкувати»**.

**Поправити текст лише для одного друку** — у вікні перегляду перед друком **«✏️ Правки»**
([Друк на DYMO](guide:labels/printing)); у базі нічого не зміниться.
