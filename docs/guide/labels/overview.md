## Що це

Minerva друкує етикетки на принтер DYMO LabelWriter для кожного артикула замовлення: P/N, кількість (QTY),
штрихкод, QR, опис, частота, роз'єм. Є три джерела:

| Що | Звідки береться | Докладно |
|---|---|---|
| **🧩 Етикетка товару з шаблону** — антени, фільтри, будь-які інші товари | один макет; артикул і кількість — з рядка замовлення, опис / частота / роз'єм — зі складу, DigiKey чи старої етикетки | [Етикетки товарів з шаблону](guide:labels/product-labels) |
| **🧩 Етикетка кабелю** `CA-…` | розбір артикула: тип кабелю, довжина, роз'єми | нижче |
| **📄 Готовий файл `.dymo`** з бази | файл, який колись зробили в програмі DYMO і завантажили в Minerva | нижче |

Окремо — [етикетка замовлення](guide:labels/order-label): номер замовлення, країна й усі артикули з кількістю.

> 💡 Головне правило: **етикетки, якої немає, не буває**. Немає файлу в базі — етикетку будь-якого товару
> Minerva складе з шаблону. Тому кнопка 🖨️ є біля кожного артикула.

### Вид товару

| Вид | Як Minerva його впізнає |
|---|---|
| антена | артикул `AN` + 4 цифри (`AN220214-01A`) або категорія товару містить «antenn» |
| фільтр | артикул `FT` + 4 цифри (`FT220407`) або категорія містить «filt» |
| кабель | артикул `CA-…` за схемою `CA-<роз'єм1>-MC<діаметр>-<довжина>-<роз'єм2>` |
| інший товар | усе решта |

## Де кнопки етикеток

- **Список замовлень** ([🛒 Продажі](/admin/sales/salesorder/)) — колонка **«🏷️ Етикетки»** (кнопка 🖨️ на кожен
  артикул), у карткового вигляду — **«🖨️ Друкувати»** біля позицій і **«🏷️ Етикетка замовлення»**.
- **Картка замовлення** — блок **«🏷️ Етикетки DYMO»**: на кожен артикул **«🖨️ Друкувати (N шт.)»**,
  **«🔄 Оновити етикетку»** / **«📎 Додати файл»** і стан (**«🧩 з шаблону антени»**, **«📄 у базі: AN220214-01A.dymo»**);
  внизу **«🏷️ Етикетка замовлення»** і **«📂 Переглянути всі етикетки»** (усі файли бази з пошуком).
- **Картка товару** ([📦 Склад → Товари](/admin/inventory/product/)) — блок **«🏷️ Етикетка DYMO»**: **«К-сть:»**,
  **«🖨️ Друкувати»**, **«📤 Замінити файл»** / **«📤 Завантажити AN220214-01A.dymo»**.
- **Список товарів** — колонка **«🏷️ Друк»**: синя **«🖨️ Друк»** — є файл у базі, сіра — буде з шаблону.
- **Сторінка [🏷️ Наклейки DYMO](/labels/)** — усі файли (нижче).

Синя кнопка — є готовий файл; сіра або з 🧩 — етикетку буде складено з шаблону.

## Клік і правий клік

**Клік** на 🖨️ робить дію за замовчуванням з [налаштувань етикеток](guide:labels/settings):

1. **Що друкувати**: файлу немає — шаблон; файл є — для антен, фільтрів і кабелів за налаштуванням **«Звідки брати
   етикетку DYMO»** (за замовчуванням — 🧩 з шаблону з актуальними даними), для інших товарів — файл.
2. **Що з нею робити** — **«Дія при натисканні 🖨️ Друкувати»**: завантажити `.dymo`, надрукувати одразу на DYMO
   ([Друк на DYMO](guide:labels/printing)) або запитати.

**Правий клік** на тій самій кнопці — меню з усіма варіантами (пункт, який робить звичайний клік, позначено
**«· клік»**):

- **«📄 Завантажити з бази»** (сіре, якщо файлу немає);
- **«🧩 Згенерувати наклейку й завантажити»**;
- **«🖨️ Згенерувати й друкувати на DYMO…»**;
- **«🔍 Перевірити дані етикетки…»** — вікно перевірки товару завжди ([докладно](guide:labels/product-labels));
- **«🖨️ Друкувати файл з бази на DYMO…»**;
- **«⚡ Одразу на принтер, без перегляду»** або **«👁 Перегляд перед друком: копії, правки…»** — протилежне до
  налаштування;
- **«⚙️ Принтер DYMO: …»** — вибрати інший принтер.

Внизу меню — що робить клік і посилання **«змінити»** на налаштування.

## Сторінка «Наклейки DYMO»

[🏷️ Наклейки DYMO](/labels/) — усі `.dymo`-файли бази: **«SKU / Part No.»** (кабелі — позначка RF cable),
**«Файл»**, **«Розмір»**, **«Змінено»**, **«Qty»** (кількість для друку) і **«Дії»**:

- **«⬇️ Завантажити»** — файл з кількістю з колонки **«Qty»**;
- 🖨️ — надрукувати цей файл одразу на DYMO;
- 🧩 — скласти ту саму етикетку з шаблону з актуальними даними (антени, фільтри, товари складу) — відкриває вікно
  перевірки;
- 🔄 — для кабелів: згенерувати заново;
- 🗑️ — видалити файл з бази (після підтвердження).

**Завантажити свої файли:** **«📤 Завантажити .dymo файл»** → виберіть один чи кілька `.dymo` → **«⬆️ Завантажити
на сервер»**. Назва файлу = артикул (`AN220214-01A.dymo`); файл цього артикула з іншою назвою
(`AN220214-01A Alt.dymo`) замінюється. Результат: ✅ created — новий, 🔄 updated — замінено.

**Згенерувати:** **«🖨️ Згенерувати наклейку»** → **«Part Number»** і **«Кількість (PCS)»**:

- кабель `CA-…` — одразу видно розбір (довжина, коаксіал, 1-й і 2-й роз'єм) → **«🖨️ Згенерувати та завантажити»**:
  файл збережеться в базі й завантажиться;
- будь-який інший артикул — відкриється вікно перевірки етикетки товару.

## Етикетка кабелю

Для `CA-MHF1-MC1.13-175-MHF4` Minerva пише:

```text
P/N: CA-MHF1-MC1.13-175-MHF4        (і штрихкод)
Qty: 20 PCS
Cable type: micro coax 1.13mm, length: 175mm
Compatible with: U.FL-1st end, MHF4-2nd end
```

Роз'єми: `MHF1` → U.FL, `MHF4`, `UMCC`, `SMA` — як є. Артикул, що не відповідає схемі, кабелем не вважається —
для нього етикетка як для іншого товару.

## Часті питання та проблеми

**Кнопка друкує не ту етикетку (старий файл замість шаблону чи навпаки)** — правий клік → потрібний пункт меню;
постійно — [налаштування етикеток](guide:labels/settings).

**«Тільки .dymo файли»** — завантажувати можна лише файли програми DYMO (`.dymo`).

**Файл є в базі, але Minerva його не бачить** — назва файлу має бути артикулом (`AN220214-01A.dymo`) або артикулом
з доповненням через пробіл чи підкреслення (`AN220214-01A Alt.dymo`, `AN220214-01A_noDK.dymo`). Регістр не важливий.

**Видалив файл — що тепер друкується?** — етикетка з шаблону (для будь-якого товару). Видалений файл не
повертається — збережіть копію на ПК (**«⬇️ Завантажити»**) перед 🗑️.
