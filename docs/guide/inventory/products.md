## Що це

**Товар** — один артикул (SKU): назва, категорія, ціни, фото, даташит, технічні параметри. Залишок у
картці не вводиться — Minerva рахує його з рухів складу ([Залишки й рухи](guide:inventory/stock)).

Список — [📦 Товари](/admin/inventory/product/), новий товар — [Додати](/admin/inventory/product/add/).

## Список товарів

### Колонки

| Колонка | Що показує |
|---|---|
| **«Sku»** | артикул (клік — картка) |
| **🖼** | мініатюра фото й 📄 даташит; бліді — немає ([Фото й даташити](guide:inventory/media)) |
| **«Категорія»** | категорія з довідника |
| **«Магазини»** | бейджі магазинів: зелений — показується, сірий — сховано, пунктир — магазин вимкнено; останній — **DigiKey** (червоний — виставлено) |
| **«На складі (точно)»** | фізичний залишок |
| **«🔒 Резерв»** | заброньовано під замовлення |
| **⚡** | стан запасу: ✅ досить, 📉 низько, ⚠️ мало, 🔥 критично, 🚫 немає |
| **«Incoming»** | очікується з відкритих закупівель |
| **«Buildable»** | скільки можна зібрати з компонентів (для товарів із BOM) |
| **«Reorder»** | 📦 скільки рекомендовано дозамовити ([Що замовити](guide:inventory/reorder)) |
| **«🏷️ Друк»** | 🖨️ етикетка DYMO; правий клік — меню ([Етикетки товарів](guide:labels/product-labels)) |
| **«⚙️ Дії»** | **«Set stock…»** — інвентаризація ([Залишки й рухи](guide:inventory/stock#інвентаризація-set-stock)) |

### Фільтри й пошук

Пошук — за артикулом, коротким артикулом і назвою. Фільтри праворуч: **«Категорія»**, **«Магазин»** (або
**«Не в жодному магазині»**), **«Фото / даташит»**, **«Життєвий цикл»**, тип, BOM, активність і
**«Параметри»** — після вибору категорії над списком з'являються кнопки технічних параметрів
([Пошук за параметрами](guide:inventory/param-search)).

### Масові дії

Позначте товари → **«Дія»**:

| **«💰 Редактор базових цін для вибраних…»** | таблиця цін за кількістю ([Базові ціни](guide:inventory/prices)) |

| **«💲 Ціна продажу = базова ціна за 1 шт.»** | «Ціна продажу» = ціна 1 шт. у валюті магазину за замовчуванням |

## Картка товару

Угорі — згорнутий блок **«🧭 Огляд і ❓ запитання»**: «які були проблеми з цим товаром? кому продавали?» —
відповідь із даних Minerva, листів і бази знань ([Огляд і Запитати](guide:ai/entity-help)).

| Розділ | Поля |
|---|---|
| основне | **«Sku»** (унікальний), **«Sku short»**, **«Name»**, **«Категорія»**, **«Kind»**, **«Bom type»**, **«Unit type»**, **«Is active»** |
| **«♻️ Життєвий цикл»** | **«Життєвий цикл»**: Активний / NRND / EOL, **«Рекомендована заміна (нова версія)»** |
| **«📦 Availability»** | залишок, резерв, очікується, можна зібрати, **«🔧 БОМ: статус компонентів»**, **«📊 Аналіз запасів»** |
| **«💰 Ціни та закупівля»** | **«Виробник»**, **«Ціна закупки»**, **«Ціна продажу»**, **«Точка дозамовлення»**, **«Термін поставки (дні)»** |
| **«💰 Базові ціни (ступені)»** | ціни за кількістю з історією змін ([Базові ціни](guide:inventory/prices)) |
| **«🏪 Інтернет-магазини»** | у яких магазинах і за якою ціною; галочка «базові ціни → магазин» |
| **«💲 Ціна на DigiKey»** | що зараз на DigiKey і що стане з цін Minerva ([Ціни DigiKey](guide:digikey/prices)) |
| **«🔗 Медіа та документи»** | даташит і фото — посилання або файл, спільний файл, **«🖼 Для сайту»** |
| **«🛃 Митне оформлення»** | **«Назва (EN/DE) для документів»**, **«HS-код (митний)»**, **«Країна виробника»**, **«Вага нетто (г/шт)»** — для CN23, Packing List, Proforma |
| **«📦 Рекомендована упаковка»** | упаковка й кількість у коробці — підказка в замовленні |
| **«📋 Рух товару»** | історія приходів, витрат і коригувань |
| **«🏷️ Етикетка DYMO»** | друк етикетки |
| **«📡 Технічні атрибути»** | параметри «назва — значення»: **«+ Додати параметр»**, **«🔄 Синх з DigiKey»** |

### Тип товару й BOM

- **«Kind»**: **Finished (sellable)** — готовий виріб для продажу; **Component (used for assembly)** —
  компонент для складання. Компонент не можна покласти на склад готової продукції і навпаки
  ([Локації](guide:inventory/stock#локації)).
- **«Bom type»**: **No BOM** або **Key components (simple BOM)** — тоді з'являється таблиця
  **«Components (BOM)»**: компонент, кількість на одиницю, необов'язковий. Minerva рахує **«Buildable»** — скільки
  виробів можна зібрати з наявних компонентів, і показує, який компонент обмежує.
- **«Unit type»**: штуки й комплекти — лише цілі числа; метри, кілограми, літри — дробові.

### Життєвий цикл

- **Активний** — звичайний товар;
- **NRND** — не рекомендовано для нових розробок; у магазинах — наліпка й посилання на заміну;
- **EOL** — знято з виробництва; на сайті продається лише залишок.

Статус діє в усіх магазинах. Лише для одного магазину — у [Асортимент і ціни](/admin/shop/shoplisting/) →
позиція → «Життєвий цикл у цьому магазині».

### Рух товару

Кнопка **«Історія»** вгорі картки відкриває **«Рух товару — FT220407»**: усі приходи, витрати, резерви й
коригування з документом (замовлення, PO) і виконавцем.

## Категорії й аліаси

- [Категорії товарів](/admin/inventory/productcategory/) — код (slug), назва, колір бейджа, порядок і митні
  дані для всієї категорії (HS-код, опис DE, країна) — їх бере CN23, якщо в товарі порожньо.
- [Аліаси товарів](/admin/inventory/productalias/) — інші назви того самого артикула (як його пише клієнт чи
  постачальник): авто-імпорт замовлень і API складу знаходять товар і за аліасом.

## Імпорт товарів з Excel

1. [📦 Товари](/admin/inventory/product/) → **«📥 Імпорт з Excel»**.
2. **«1. Файл»** — виберіть `.xlsx` → **«🔍 Аналізувати файл →»**.
3. **«2. Маппінг»** — аркуш і для кожної колонки Excel поле Minerva (SKU обов'язковий); колонки без поля
   ігноруються. **«Конфлікт (SKU вже є):»** — **«⏭ Пропустити існуючі»** або **«✏️ Оновити існуючі»**.
   Галочка **«🧪 Тестовий запуск (без збереження)»** — спершу перевірити.
4. **«✅ Імпортувати →»** → **«3. Результат»**.

Поле **«Початковий залишок (ADJUSTMENT)»** одразу записує коригування складу. Готовий шаблон —
[Шаблон Excel](/dashboard/import-template/inventory/) ([Імпорт даних](guide:system/import)).

## Часті питання та проблеми

**Залишок у картці не редагується** — так задумано: залишок = сума рухів. Змініть його через
**«Set stock…»** або транзакцію ([Залишки й рухи](guide:inventory/stock)).

**Товар не видно в магазині** — товар має бути в асортименті магазину й позначений «показувати»
([Асортимент і ціни](guide:shop/catalog-prices)); колонка **«Магазини»** показує, де він є.

**Немає кнопок параметрів над списком** — спершу виберіть категорію у фільтрі праворуч.

**Неактивний товар** (**«Is active»** вимкнено) не з'являється в огляді складу й аналізі запасів.
