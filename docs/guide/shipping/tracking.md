## Що це

Трек-номер з'являється у відправленні після бронювання (або його вписують вручну). Далі Minerva сама питає
перевізника про статус і оновлює **відправлення** й **замовлення**: «В дорозі», «Доставлено», очікувана дата,
затримка. Усі трек-номери разом — на сторінці [📡 Відслідковування замовлень](/admin/shipping/shipment/order-tracking/).

## Як увімкнути автоматичний трекінг

1. Відкрийте [налаштування доставки](/admin/shipping/shippingsettings/) (також [⚙️ Система → 🔌 Інтеграції](/admin/config/integrations/) →
   «Авто-трекінг відправлень» → **«⚙️ Налаштувати»**).
2. Блок **«🔄 Автоматичний трекінг»**: галочка **«Автоматичне оновлення трекінгу»**, **«Інтервал оновлення (хвилини)»**
   (30 за замовчуванням).
3. **«Зберегти»**.

Оновлюються всі відправлення зі статусом **📤 Передано перевізнику**, **🏷️ Етикетка готова**, **🚚 В дорозі**.
**«Останній запуск»** показує, коли це було востаннє. **«🔄 Запустити оновлення зараз»** — оновити все одразу, не
чекаючи інтервалу.

> ℹ️ Запуски робить планувальник сервера (контейнер `cron`) кожні кілька хвилин; Minerva сама пропускає запуск,
> якщо інтервал ще не минув. Якщо «Останній запуск» давно не змінюється — перевірте, чи працює `cron` (це робить
> адміністратор сервера).

Оновити одну посилку вручну — у картці відправлення **«🔄 Оновити трекінг»** (або **«🔄 Оновити статус»** для Jumingo).

## Сторінка «Відслідковування замовлень»

[📡 Відслідковування](/admin/shipping/shipment/order-tracking/) (кнопка в [списку відправлень](/admin/shipping/shipment/)) —
усі замовлення з трек-номером:

| Колонка | Що показує |
|---|---|
| **Замовлення** | номер і джерело; кілька трек-номерів в одному замовленні — окремі рядки «📦 Part 1 / 2» |
| **Трекінг** | номер — посилання на сайт перевізника |
| **Перевізник** | визначається за форматом номера: 10 цифр — DHL Express, `1Z…` — UPS, `JD…` — DHL Paket, 14 цифр, що починаються з 20 або 59, — Нова Пошта, `RR123456789DE` — пошта |
| **Джерело** | **🔗 Minerva API** — відправлення створене в Minerva; **📦 Зовнішнє** — трек-номер вписано в замовлення вручну |
| **Статус замовлення** | статус і дата відправки / доставки |
| **Дія** | **🔄 Оновити** — запитати перевізника зараз; **🔗 Перейти** — відкрити сайт перевізника |

**✅ Minerva тречить** — статус оновлюється з API (Jumingo, DHL). **👁️ Ручне відслідковування** — Minerva лише
дає посилання; дивіться статус на сайті перевізника. **«⚠️ Невідомий — перевір вручну»** — формат номера не
розпізнано.

## Додати трекінг вручну

Посилку відправили не через Minerva (на сайті служби, на пошті) — щоб вона теж відстежувалась:

1. [📡 Додати трекінг](/admin/shipping/shipment/add-tracking/) у меню **🚚 Доставка**.
2. **«Номер трекінгу»** (обов'язково), **«Перевізник»**, **«Референс»**.
3. **«Пов'язати з замовленням»** — почніть вводити номер замовлення або клієнта й виберіть.
4. За бажанням: **«Ім'я отримувача»**, **«Країна відправника (ISO 2)»**, **«Країна отримувача (ISO 2)»**,
   **«Вартість доставки»**, **«Валюта»**, **«URL етикетки (PDF)»**, **«Нотатки»**.
5. **«💾 Зберегти»** — створиться відправлення зі статусом **🚚 В дорозі** і відкриється його картка.

Трек-номер для відправлення-чернетки чи після бронювання без номера — у картці відправлення, блок
**«📝 Трекінг-номер»** → **«💾 Зберегти»**. Або просто впишіть його в поле «Трекінг-номер» замовлення — воно
з'явиться на сторінці «Відслідковування» як **📦 Зовнішнє**.

## Перевірити будь-який номер

- [🔍 DHL Трекінг](/admin/shipping/shipment/dhl-track-lookup/) — DHL Express;
- [🔍 UPS Трекінг](/admin/shipping/shipment/ups-track-lookup/) — номери `1Z…`;
- [🔍 FedEx Трекінг](/admin/shipping/shipment/fedex-track-lookup/).

Введіть номер → **«Знайти»**: статус, події, дата доставки. Нічого в Minerva не змінюється.

## Затримки й сповіщення

Коли перевізник підтверджує затримку або очікувана дата минула, у картці відправлення — **«🚨 Вспізнення
підтверджено»**, на шкалі етапів — **«! Затримка!»**. Minerva надсилає сповіщення в Telegram
([Сповіщення](guide:system/notifications)). У [налаштуваннях доставки](/admin/shipping/shippingsettings/) блок
**«🔔 Сповіщення про затримки»**: **«Сповіщення про затримки»** (увімк. / вимк.) і **«Частота сповіщень про
затримки»** — один раз, щодня, кожну синхронізацію.

## Захист статусів

Блок **«⚙️ Пріоритет та захист статусу»** у [налаштуваннях доставки](/admin/shipping/shippingsettings/):

| Налаштування | Що робить | Рекомендовано |
|---|---|---|
| **«Пріоритет при конфлікті статусів»** | що робити, коли DigiKey каже «Доставлено», а UPS — «В дорозі»: **Вищий статус** / **Перевізник** / **Маркетплейс** | Вищий статус або Перевізник |
| **«Пріоритет трекінг-номера»** | є трек-номер — спершу пряме API перевізника (DHL, UPS), потім Jumingo | увімкнено |
| **«Тільки підвищувати статус»** | статус посилки не відкочується назад («В дорозі» → «Етикетка готова») | увімкнено |
| **«Блокувати статус після «Доставлено»»** | трекінг не поверне замовлення з «Доставлено» у «Відправлено» | увімкнено |
| **«Довіряти кешу при збої API»** | перевізник не відповідає — взяти останній збережений статус | **вимкнено** (старий кеш може хибно закрити замовлення) |

## Правила трекінгу

Хто відстежує посилку, визначають правила: блок **«📋 Правила трекінгу»** → **«✏️ Редагувати правила»**
([Правила трекінгу](/admin/shipping/trackingrule/)).

- **«Тип перевізника»** — до якого перевізника правило;
- **«Префікс трекінг-номера»** — правило лише для номерів, що так починаються (`1Z` — UPS, `JD` — DHL Paket,
  `7489` — DHL Express); порожньо — за типом перевізника;
- **«Пріоритет»** — 1 основний, 2 і 3 — запасні: не вдалося першим — Minerva пробує наступний;
- **«Сервіс трекінгу»** — Jumingo, DHL (MyDHL+ API), DHL Tracking Unified, UPS, FedEx; **«Увімкнено»**.

Правил немає — Minerva пробує Jumingo. Кожна спроба записується: блок **«📝 Лог спроб трекінгу»** →
**«📋 Відкрити лог трекінгу (N записів) →»** (сервіс, успіх, знайдений статус, помилка, час).

## Часті питання та проблеми

**Статус не оновлюється** — перевірте, що автотрекінг увімкнено й «Останній запуск» свіжий; у лозі трекінгу —
чи є помилки (немає ключа, перевізник не знає номера).

**DHL Paket не відстежується** — потрібен **«Tracking API Key»** у картці DHL [перевізника](guide:shipping/carriers)
і правило з сервісом **DHL Tracking Unified** (префікс `JD`).

**Перевізник показує застарілий статус** — у картці відправлення **«🔧 Статус вручну»** → потрібний статус →
**«Застосувати»** (змінює й замовлення; перевізнику нічого не надсилається).
