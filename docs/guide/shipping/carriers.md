## Що це

**Перевізник** у Minerva — це ваш акаунт у службі доставки з ключами API і даними відправника. З нього
Minerva запитує тарифи, бронює відправлення, отримує етикетку й трек-номер. Кожен активний перевізник
з'являється в блоці **«🚚 Перевізник»** форми відправлення і бере участь у **«📊 Порівняти тарифи»**.

| Тип | Що вміє в Minerva |
|---|---|
| **UPS** | тарифи, бронювання, етикетка, митна декларація, свій інвойс (Paperless), виклик кур'єра, трекінг, імпорт рахунків — [UPS](guide:shipping/ups) |
| **DHL** | DHL Express (MyDHL API): тарифи, бронювання, етикетка, виклик кур'єра, скасування, трекінг — [DHL, Jumingo, FedEx](guide:shipping/other-carriers) |
| **FedEx** | тарифи, бронювання, етикетка, трекінг |
| **Jumingo (агрегатор)** | тарифи багатьох служб, створення відправлення, документи; оплата — на сайті Jumingo |
| **Інше** | без API: для відправлень, де трек-номер ви вписуєте самі (Нова Пошта, пошта) |

## Як додати перевізника

1. Відкрийте [🚛 Перевізники → Додати](/admin/shipping/carrier/add/).
2. Блок **«🚚 Перевізник»**: **«Назва»** (як ви його бачитимете, напр. «UPS Sevskiy»), **«Тип»**, галочки
   **«Активний»** і **«За замовчуванням»** (за замовчуванням може бути лише один — інші знімуться самі).
3. Блок **«🔑 API налаштування»** — ключі з кабінету розробника перевізника (таблиця нижче). Поля ключів
   приховані, як паролі: вставляйте їх тут, у картці перевізника, і більше ніде.
4. Блок **«📤 Дані відправника»** — ваша адреса: **«Ім'я відправника»**, **«Компанія відправника»**,
   **«Вулиця, будинок»**, **«Місто»**, **«Поштовий індекс»**, **«Країна (ISO 2)»** (`DE`), **«Телефон відправника»**,
   **«Email відправника»**. Ці дані підставляються в кожне нове відправлення цим перевізником.
5. **«Зберегти»**. У списку колонка **«API ключ»** покаже **✅ Так**.

### Які поля заповнювати

| Тип | «API ключ» | «API Secret / пароль» | «Connection UUID / Account №» | «API URL / режим» |
|---|---|---|---|---|
| UPS | Client ID | Client Secret | Account Number (6 символів) | `sandbox` — тест, порожньо — робочий |
| DHL | API Key (MyDHL) | API Secret | Account Number (9 цифр) | `test` — тест, порожньо — робочий |
| FedEx | Client ID | Client Secret | Account Number | `sandbox` — тест, порожньо — робочий |
| Jumingo | X-AUTH-TOKEN | — | UUID інтеграції | порожньо |

**«Tracking API Key»** — лише для DHL: окремий ключ «Shipment Tracking – Unified» з developer.dhl.com
(My Apps). Він потрібен, щоб відстежувати DHL Paket і інші посилки DHL, а не лише Express.

> ⚠️ У тестовому режимі (`sandbox` / `test`) перевізник не створює справжніх відправлень і не списує гроші —
> зручно для першої перевірки. Не забудьте очистити поле **«API URL / режим»**, коли все запрацює.

## Кнопки в картці перевізника

Угорі картки збереженого перевізника з ключем:

- UPS — **«💳 UPS Billing»** (імпорт рахунків UPS у витрати, див. [UPS](guide:shipping/ups#рахунки-ups-у-бухгалтерії)),
  **«📋 UPS Лог»** (останні запити до UPS і відповіді), **«🔬 UPS Debug»** (покрокова перевірка: токен, запит тарифу);
- DHL, FedEx, Jumingo — **«📋 DHL Лог»** / **«📋 FEDEX Лог»** / **«📋 JUMINGO Лог»**.

Скільки записів зберігає лог — у [налаштуваннях доставки](/admin/shipping/shippingsettings/)
(**«UPS лог — макс. записів»**, **«API лог — макс. записів (DHL/FedEx/Jumingo/DigiKey)»**).

## Список перевізників

У [списку](/admin/shipping/carrier/) видно тип, відправника, країну й чи є ключ. Галочки **«Активний»** і
**«За замовчуванням»** можна змінювати прямо в списку й натиснути **«Зберегти»** внизу.

- Вимкнений перевізник не показується у формі відправлення й не опитується під час порівняння тарифів;
  старі відправлення з ним лишаються.
- Перевізник **за замовчуванням** стоїть першим.

## Приклади

**Тест UPS перед запуском.** Створіть перевізника «UPS Test», **Тип** — UPS, вставте Client ID / Client Secret
тестового застосунку UPS, Account Number, **«API URL / режим»** — `sandbox`. Відкрийте **«🔬 UPS Debug»** —
крок отримання токена має бути зеленим. Потім оформіть пробне відправлення.

**Два акаунти DHL.** Можна мати двох перевізників одного типу (напр. «DHL Express DE» і «DHL Express Export»)
з різними номерами акаунта. У формі відправлення вибираєте потрібний.

## Часті питання та проблеми

**«UPS Carrier «…»: заповніть API ключ (Client ID), API Secret (Client Secret) і Connection UUID (Account Number).»** —
у картці UPS порожнє одне з трьох полів.

**У порівнянні тарифів немає перевізника** — він вимкнений (**«Активний»**) або без ключа. Помилку конкретного
перевізника видно рядком у таблиці тарифів; подробиці — у його лозі.

**Відправник не той** — дані відправника беруться з картки перевізника. Змініть їх там або виправте у формі
конкретного відправлення (поле, яке ви змінили вручну, Minerva вже не перезаписує).

**Перевізника не можна видалити** — до нього прив'язані відправлення. Зніміть галочку **«Активний»**.
