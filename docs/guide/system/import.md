## Що можна імпортувати

| Що | Разово (майстер) | За розкладом (авто-імпорт) |
|---|---|---|
| **Замовлення** з рядками | [Імпорт замовлень з Excel](/admin/sales/salesorder/import-excel/) — див. [Імпорт замовлень](guide:sales/import) | так, тип **«🛒 Замовлення (Sales)»** |
| **Товари** (каталог) | [Імпорт товарів з Excel](/admin/inventory/product/import-excel/) | так, **«📦 Товари (Products)»** |
| **Прихід на склад** | майстер авто-імпорту без назви профілю | так, **«📥 Прихід на склад (Receipt)»** |
| **Коригування залишків** | майстер авто-імпорту без назви профілю | так, **«🔧 Коригування залишків (Adjust)»** |

Усе зібрано на сторінці [⚙️ Система → Імпорт даних](/dashboard/import/): картки з кнопками
**«⬆️ Відкрити wizard»**, **«📄 Шаблон .xlsx»** (готовий файл з потрібними колонками) і **«▶ Колонки файлу»**
(перелік полів, ✱ — обов'язкові).

## Правила для файлів

- **Формат** — `.xlsx` (Excel 2007+); авто-імпорт приймає ще `.xls` і `.csv`. Перший рядок — заголовки колонок.
- **Дати** — `2026-10-29` або `29.10.2026`. Числа — з крапкою або комою.
- **Клієнти** при імпорті замовлень створюються самі за email і ім'ям, без дублів.
- **Джерело** замовлення (`source`) має збігатися з кодом джерела в [Джерелах замовлень](guide:sales/sources).
- Назви колонок не обов'язково такі, як у шаблоні: на кроці «Маппінг» ви вказуєте, яка колонка файлу — яке поле.

## Імпорт товарів з Excel

1. [Склад → Товари](/admin/inventory/product/) → **«📥 Імпорт з Excel»** (або картка «📦 Товари та склад» на
   сторінці «Імпорт даних»).
2. **«Оберіть файл Excel»** → **«Аналізувати файл →»**.
3. **«Лист (аркуш) Excel:»** — якщо в книзі кілька аркушів.
4. Таблиця **«Маппінг колонок → поля бази даних:»** — для кожної колонки виберіть поле або
   **«— не імпортувати —»**. Обов'язкове лише `sku`.
5. **«Конфлікт (SKU вже є):»** — **«Пропустити існуючі»** або **«Оновити існуючі»**.
6. Залиште **«Тестовий запуск (без збереження)»** → **«Імпортувати →»**. Результат: **«Створено»**,
   **«Оновлено»**, **«Пропущено»**, **«Помилок»** і таблиця помилок по рядках — у базі нічого не змінилось.
7. Усе гаразд — **«Запустити реальний імпорт»**.

Поля товару: `sku` ✱, `name`, `category`, `manufacturer`, `purchase_price`, `sale_price`, `reorder_point`,
`lead_time_days`, `initial_stock`, `unit_type`, `datasheet_url`, `image_url`, `hs_code`, `country_of_origin`,
`net_weight_g`, `is_active`. Колонка `initial_stock` створює рух складу «коригування» на цю кількість.

Приклад файлу:

| sku | name | sale_price | reorder_point | initial_stock |
|---|---|---|---|---|
| FT220407 | Filter 2.4 GHz SMA | 12,50 | 20 | 100 |

Колонка `category` — код (slug) категорії, як у довіднику категорій складу.

## Авто-імпорт: майстер

[⚙️ Система → Авто-імпорт](/admin/autoimport/autoimportprofile/) → **«Створити профіль»** (або одразу
[майстер](/admin/autoimport/autoimportprofile/run/)). Три кроки: **«1. Джерело»** → **«2. Маппінг»** →
**«3. Результат»**.

**Крок 1 — «📂 Джерело даних»:**

1. **«Тип імпорту:»** — замовлення, товари, прихід або коригування.
2. **«Джерело файлу:»**
   - **«📤 Файл з ПК»** — разове завантаження;
   - **«🌐 URL / Google Sheets»** — адреса таблиці (див. нижче);
   - **«📁 Папка на сервері»** — **«Шлях до папки на сервері:»** і **«Маска файлів:»** (наприклад `*.xlsx;*.csv`).
3. **«💾 Профіль (опційно — для планового запуску)»**:
   - **«Назва профілю:»** — порожньо = одноразовий імпорт без профілю;
   - **«Інтервал (хв):»** — як часто брати нові файли;
   - **«Конфлікти (SKU/замовлення вже є):»** — пропустити або оновити;
   - **«🧪 Тестовий запуск (без збереження в БД)»**, **«📩 Сповіщення після запуску»** (email / Telegram з
     [Налаштувань сповіщень](guide:system/notifications)), **«📁 Архівувати оброблені файли»** (у підпапку `_done/`).
4. **«🔍 Аналізувати →»**.

**Крок 2 — «📋 Маппінг колонок»:** **«Лист Excel:»**, таблиця **«Поле системи»** / **«Колонка у файлі»** /
**«Приклад значення»**. Поля з ✱ обов'язкові; непотрібні — **«— не використовувати —»**. Minerva сама
підбирає колонки за назвами (українською, німецькою, англійською). → **«✅ Імпортувати →»**.

**Крок 3 — результат:** **«Створено»**, **«Оновлено»**, **«Пропущено»**, **«Помилок»**, **«⚠ Деталі помилок»**,
**«💾 Профіль збережено»**. Нульовий результат Minerva пояснює: не замаплені обов'язкові колонки, усі записи
вже є, у файлі лише заголовки.

## Авто-імпорт: профілі й журнал

У списку [профілів](/admin/autoimport/autoimportprofile/) — тип, джерело, **«Активний»** (можна вимкнути
прямо в списку), інтервал, останній і наступний запуск, статус і кнопки:

- **▶** — запустити зараз;
- **🧪** — тестовий запуск без запису в базу;
- **⚙** — змінити профіль у майстрі.

[Логи авто-імпорту](/admin/autoimport/autoimportlog/): **«✅ Успішно»**, **«🧪 Dry-run»**, **«❌ Помилка»**,
**«⏭ Дублікат»** — той самий файл двічі не імпортується (Minerva впізнає його за вмістом).

Розклад сервера Minerva щохвилини перевіряє профілі: кожен **«Активний»** профіль запускається сам, коли
настає його **«Наступний запуск»** (через **«Інтервал (хв)»** після попереднього), — один раз, навіть якщо
імпорт іде довго чи впав посередині. Вимкнений профіль не запускається; **▶** запускає одразу, без огляду на
розклад.

## Google Sheets і папка на сервері

**Google Sheets:**

1. У таблиці: **Файл → Поділитися → Усі, хто має посилання** (переглядач).
2. З адреси таблиці скопіюйте ID — частину між `/d/` і `/edit`.
3. У майстрі вставте `https://docs.google.com/spreadsheets/d/<ID>/export?format=csv`.

**Папка на сервері** — шлях, який бачить Minerva на NAS (наприклад `/volume1/imports/`). Папку для Minerva
підключає адміністратор NAS. Оброблені файли переносяться в `_done/`, якщо ввімкнено архівування.

## Поради

- Спершу завжди тестовий запуск — він показує помилки по рядках, нічого не змінюючи.
- Перед великим імпортом зробіть [резервну копію](guide:system/backup).
- Імпортували не те — на сторінці «Імпорт даних» є посилання на очищення, але воно видаляє **всі**
  замовлення чи товари, а не лише імпортовані; на робочій системі краще відновити копію.

## Часті питання та проблеми

**«Оберіть файл для завантаження.» / «Введіть URL.» / «Введіть шлях до папки.»** — на кроці 1 не вказано джерело.

**«Помилка завантаження URL»** — таблиця Google не відкрита за посиланням або адреса без `export?format=csv`.

**«Помилка читання папки»** — Minerva не бачить цю папку на сервері.

**Усі рядки «Пропущено».** Такі записи вже є, а конфлікти — «Пропустити»; виберіть «Оновити», якщо треба оновити.

**«Сесія застаріла — починайте спочатку.»** — між кроками минуло забагато часу; запустіть майстер знову.
