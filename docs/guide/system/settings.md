## Сторінка «Система»

Клік на заголовок групи **«⚙️ Система»** у меню відкриває [сторінку з плитками](/dashboard/system/):

- **рядок стану** вгорі: **«💾 Backup:»** коли була остання копія (зелений — сьогодні або вчора, жовтий — до
  тижня, червоний — давно або ніколи), **«📡 Авто-трекінг:»**, **«🔑 API ключів:»**, **«⏳ Не відправлено:»**;
- **«⚙️ Система»** — плитки всіх налаштувань (**«✏️ Налаштувати плитки»** — змінити набір);
- **«🧪 Онбординг та тестові дані»**, **«📄 Документи та звітність»**, **«⚠️ Небезпечна зона»**,
  **«🕐 Недавні дії»**.

## Системні налаштування

[Системні налаштування](/admin/config/systemsettings/) — одна сторінка для всієї фірми:

| Блок | Поля | Навіщо |
|---|---|---|
| **«🏢 Компанія»** | **«Назва компанії»**, **«Логотип»**, **«Валюта за замовчуванням»**, **«Часовий пояс»** | назва — у запрошеннях, звітах, брифінгу й AI-оглядах («наша фірма») |
| **«📦 Активні модулі»** | **«Активні модулі»**, **«Рівень бухгалтерії»** | вибір з майстра першого запуску |
| **«💰 Фінанси»** | **«ПДВ / MwSt за замовчуванням (%)»** | підставляється в нові рахунки-фактури (наприклад 19) |
| **«📐 Одиниці виміру та формати»** | **«Одиниця ваги»** (кг / г / lb), **«Одиниця розмірів»** (см / мм / in), **«Формат коду країни»** (DE або DEU) | відправлення й пакувальні документи |
| **«⚙️ Система»** | **«Онбординг завершено»** | зніміть — і майстер першого запуску відкриється знову |
| **«🌐 Публічна інформація»** | **«Слоган»**, **«Контактний email»**, **«Телефон підтримки»**, **«Telegram підтримки»** | публічна сторінка й листи клієнтам |
| **«🔗 Домен системи»** | **«Протокол»** (HTTP / HTTPS), **«Домен системи»** | адреса в посиланнях листів (скидання пароля) |
| **«🔑 Ліцензія»** | пакет, ключ, строк дії | згорнутий блок |

**Домен системи** — точна адреса, за якою Minerva відкривається ззовні, без `https://`: наприклад
`minerva.example.com` і **«Протокол»** — HTTPS. Після зміни надішліть собі «Забули пароль?» і перевірте
посилання в листі.

> ℹ️ Щоб сховати модуль для всіх, користуйтеся [Реєстром модулів](/admin/core/moduleregistry/) — саме він
> вирішує, які модулі працюють ([Користувачі, ролі й доступ](guide:system/users-roles)). Галочки
> **«Активні модулі»** тут лише запам'ятовують вибір майстра.

## Реквізити компанії для документів

[💰 Бухгалтерія → Налаштування компанії](/admin/accounting/companysettings/) — дані, що друкуються в PDF-рахунках
і Proforma: назва й юридична назва, адреса, **«VAT ID / ІПН»**, **«IBAN»**, банк, **«SWIFT/BIC»**, **«EORI номер»**,
**«TAX ID (Steuernummer)»**, контакти, логотип, підпис і печатка, **«Префікс рахунку»** і **«Наступний номер
рахунку»**. Заповніть один раз перед першим рахунком.

## Налаштування документів

[Налаштування документів](/admin/config/documentsettings/) — PDF, які Minerva робить із замовлення:
**«Мова документів»** (English, Deutsch / English, лише Deutsch), ціни й нотатка в пакувальному листі, умови
оплати й примітки Proforma, тип і опис CN23, чи показувати блок «Автоматичні документи» в картці замовлення.
Детальніше — [Документи замовлення](guide:sales/order-documents). Шаблони Word для Commercial Invoice, Packing
List і Angebot — на їхніх сторінках ([Commercial Invoices](guide:sales/commercial-invoices),
[Налаштування й шаблон Word](guide:offers/settings)).

## Інтеграції

[⚙️ Система → Інтеграції](/admin/config/integrations/) — огляд підключених сервісів, лише для перегляду. Кожна
картка показує стан (**«✅ Активна»**, **«⚠️ …»**, **«⏸ Вимкнено»**), головні параметри й кнопку
**«⚙️ Налаштувати»**:

- **DigiKey Marketplace** — режим, синхронізація, авторизація, остання синхронізація; посилання на замовлення
  Marketplace і звірку ([DigiKey](guide:digikey/listings));
- **перевізники** (UPS, DHL, Jumingo…) — чи є ключ API, чи за замовчуванням ([Перевізники](guide:shipping/carriers));
- **Авто-трекінг відправлень** — інтервал, останній запуск, **«🔄 Запустити зараз»** ([Трекінг](guide:shipping/tracking));
- **Email (SMTP)** і **Telegram Bot** — **«📧 Тест email»**, **«📱 Тест Telegram»** ([Сповіщення](guide:system/notifications)).

Інші підключення мають свої сторінки: ключ Anthropic для AI — [Minerva AI](guide:ai/minerva-ai), скриньки пошти —
[Скриньки й синхронізація](guide:mail/mailboxes), askDANTE — [Налаштування askDANTE](guide:worktime/setup),
Google / Outlook — [Підключення календарів](guide:calendar/connections), Stripe — [Оплата](guide:shop/payments),
RAG — [База знань](guide:ai/knowledge-base), ключі API для сайту й CRM — [Ключі API](guide:api/keys).

## Власна тема кольорів

[Тема кольорів (Custom)](/admin/config/themesettings/) — свої кольори фону, тексту, акцентів, статусів, верхньої
панелі, бічного меню, рамок і кнопок. Порожнє поле — колір з поточної теми.

- **«📥 Пресети»** — почати з 🌙 Темна, ☀️ Світла або ⚜️ Minerva; **«🗑️ Очистити все»** — скинути.
- **«🗂️ Мої профілі»** — зберегти набір кольорів під назвою й повернутися до нього.
- **«💾 Зберегти на ПК»** / **«📤 Завантажити з ПК»** — файл `.json` з темою.
- Після **«Зберегти»** унизу бічного меню з'являється кнопка **🎨** — кожен може вибрати цю тему.

## Демо-дані й очищення

На [сторінці «Система»](/dashboard/system/):

- **«🧪 Створити демо-дані»** — тестові товари, клієнти, замовлення, рахунки, відправлення, задачі (можна
  вибрати сценарії й масову генерацію) → **«▶ Завантажити»**. Усе позначено як демо;
- **«🗑️ Видалити демо-дані»** — прибрати лише тестові записи;
- **«⚠️ Небезпечна зона»**: **«🗑️ Транзакційні дані»** видаляє замовлення, клієнтів, рух складу, рахунки,
  платежі, витрати, відправлення й задачі (для підтвердження треба ввести `ОЧИСТИТИ`); **«💥 Factory Reset»** —
  ще й закупівлі, товари, категорії, склади, постачальників, джерела продажів, перевізників, скидає реквізити
  компанії й знову вмикає майстер першого запуску (ввести `ПОВНЕ ОЧИЩЕННЯ`). Користувачі лишаються.

> ⚠️ Демо-дані й очищення — лише для нової або тестової системи. Перед будь-яким очищенням зробіть
> [резервну копію](guide:system/backup): відновити видалене інакше не можна.

## Хто може змінювати

Сторінки налаштувань відкриває адміністратор (і той, кому в профілі дано модуль «Налаштування» з правом
редагування) — [Користувачі, ролі й доступ](guide:system/users-roles).

Паролі й ключі в налаштуваннях (SMTP, IMAP, Telegram-бот, ліцензія) не показуються: у полі —
**«збережено: abcd••••••••wxyz — введіть новий, щоб замінити»**. Щоб змінити — впишіть новий; порожнє поле лишає
збережений.

## Часті питання

**У посиланні з листа «Забули пароль?» неправильна адреса (localhost).** Заповніть **«Домен системи»** і
**«Протокол»** у [Системних налаштуваннях](/admin/config/systemsettings/).

**У PDF-рахунку немає IBAN чи логотипа.** Заповніть [Налаштування компанії](/admin/accounting/companysettings/).
