## Що це

Замовлення покупців DigiKey Marketplace Minerva забирає сама й створює в [🛒 Продажах](/admin/sales/salesorder/?source=digikey)
з **«Джерелом»** `digikey` і номером замовлення DigiKey. Далі звичайний шлях замовлення (склад, документи,
відправлення), а DigiKey отримує від Minerva підтвердження замовлення, трек-номер і — для покупців з ЄС — ваш
інвойс.

| Стан на DigiKey | Статус у Minerva |
|---|---|
| New / очікує прийняття | Отримано |
| Accepted, ShippingInProgress | В обробці |
| Shipped | Відправлено |
| Received / Delivered / Completed | Доставлено |
| Cancelled / Rejected | Скасовано |

## Налаштування

Сторінка [🛒 DigiKey](/admin/bots/digikeyconfig/) (підключення API — [Лістинги DigiKey](guide:digikey/listings)):

- **«⏰ Синхронізація замовлень»**:
  - **«Синхронізація увімкнена»** і **«Інтервал синхронізації (хвилин)»** (рекомендовано 15–60);
  - **«Sandbox режим (тестовий)»** — для перевірки без реальних замовлень; для роботи вимкніть;
  - **«Оновлювати статус замовлення при синхронізації»** — статус з DigiKey (лише вперед). Вимкніть, якщо статус
    веде трекінг перевізника або ви вручну;
  - **«Авто-підтвердження на DigiKey»** — **Мануально** / **Завжди** (одразу при надходженні) / **Якщо є на складі**
    (лише коли всі товари є);
- **«🛒 Marketplace API (3-legged OAuth)»** → **«Авто-генерація інвойсу для ЄС»** — при підтвердженні відправки
  до ЄС Minerva сама генерує інвойс, якщо його ще немає;
- **«💬 Повідомлення DigiKey»** — авто-перевірка повідомлень покупців і сповіщення Telegram / email;
- **«🔔 Сповіщення про збої API»** — повтори й кому писати, якщо DigiKey API не відповідає.

## Вхідні замовлення

Блок **«🔌 Дії»** → **«🛒 Замовлення»**:

- **«📋 Замовлення»** — [📋 DigiKey Marketplace — Вхідні замовлення](/admin/bots/digikeyconfig/marketplace-orders/):
  картки замовлень прямо з DigiKey — номер, покупець, дата, Deadline відправки, email, місто й країна, позиції,
  сума, PO покупця, стан. Кнопки: **«✅ Підтвердити»** (нове замовлення), **«📤 Відправити»** і **«📦 Pack List»**
  (прийняте замовлення, яке вже є в Minerva). Внизу — **«Наступні →»** / **«← Попередні»**;
- **«🔄 Синхронізувати»** — забрати нові замовлення зараз (повідомить «+N замовлень, +M рядків, оновлено K» і SKU,
  яких немає на складі);
- **«🔍 Звірити з DigiKey»** — див. нижче;
- **«💬 Messages Hub»** — повідомлення покупців.

## Як обробити замовлення DigiKey

1. Замовлення з'являється в Продажах зі статусом **«Отримано»** (якщо не ввімкнено авто-підтвердження).
2. Картка замовлення → панель **«🔧 DigiKey API Actions»** → **«✅ Підтвердити на DigiKey»**. Статус стане
   **«В обробці»**.
3. Зберіть товар. Документи: **«📦 Pack List (DigiKey)»** серед документів замовлення (💾 — зберегти в папку
   замовлення).
4. Створіть відправлення ([Відправлення](guide:shipping/shipments)) — з етикеткою й трек-номером.
5. Підтвердіть відправлення на DigiKey одним із способів:
   - на сторінці відправлення банер **«🛒 Підтвердити відправлення в DigiKey?»** → **«✅ Підтвердити автоматично»**
     (або **«✏️ Вручну»** — форма нижче);
   - у картці замовлення → **«📤 Confirm Shipment on DigiKey»**.
6. Форма **«📤 Відправити #… на DigiKey»**: **«Трек-номер»** (обов'язково), **«Перевізник»** (підбирається з
   замовлення), кількість по кожній позиції (змінюйте лише при частковому відправленні); для ЄС — інвойс
   (див. нижче). **«📤 Підтвердити відправлення на DigiKey»**.
7. DigiKey отримає трек-номер; статус стане **«Відправлено»** і в Minerva, і на DigiKey. Картка замовлення покаже
   **«✅ Підтверджено на DigiKey Marketplace»** з трек-номером і Supplier Invoice Number.

> ⚠️ Підтвердження відправлення незворотне — перевірте трек-номер. Якщо трек-номер є, а відправку ще не
> підтверджено, картка замовлення попереджає **«Відправку не підтверджено на DigiKey Marketplace»**.

Ще в панелі **«🔧 DigiKey API Actions»**: **«🔄 Трекінг з DigiKey»** — взяти трек-номер і кур'єра з DigiKey у поля
форми; **«📦 Відстежувати»** — створити відправлення в розділі Доставка з цим трек-номером.

## Інвойс для покупців з ЄС

Для замовлення з країни ЄС DigiKey просить ваш рахунок: **«Номер рахунку постачальника (Supplier Invoice Number)»**,
**«Сума рахунку без ПДВ (Net Invoice Amount)»** і файл **«Рахунок-фактура ПДВ (Supplier VAT Invoice)»**. Форма
відправлення підставляє їх з уже згенерованого інвойсу. Якщо ввімкнено «Авто-генерація інвойсу для ЄС» і нумерація
збігається, інвойс створюється сам. Для замовлень не з ЄС ці поля не потрібні.

Якщо останній номер інвойсу в Minerva й на DigiKey різний — **«⚠️ Розбіжність нумерації інвойсів!»**: виберіть
**«Використати нумерацію DigiKey → #…»**, **«Використати нумерацію системи → #…»** або **«Ввести номер вручну»**.

**Інвойси DigiKey** — [🧾 DigiKey](/invoices/) у меню **🚚 Доставка → Інвойси** (сторінка «📄 Invoices»):

- **«＋ Згенерувати інвойс»** → номер замовлення DigiKey (або вибір з **«Останні замовлення DigiKey»**, фільтр
  **«Тільки ЄС»**) → **«🔍 Отримати дані з DigiKey API»** → перевірте номер інвойсу, VAT ID, суми →
  **«✅ Підтвердити та згенерувати інвойс»**. DigiKey API недоступний — **«✏️ Ручне введення даних»**;
- **«📁 Додати існуючий»** — зареєструвати інвойс, зроблений поза Minerva (номер, замовлення, сума, файл .docx);
- у таблиці: 🖨️ PDF, ⬇ .docx, 🔍 деталі, 🗑; суми без ПДВ і разом (USD);
- **«⚙️ Шаблон інвойсу»** — активний шаблон Word, **«📤 Завантажити новий шаблон (.docx)»**, **«📋 Змінні шаблону»**,
  **«⬇️ Демо-інвойс (.docx)»**.

> ℹ️ Ці інвойси — лише для DigiKey Marketplace. Рахунки для інших замовлень — [Commercial Invoices](guide:sales/commercial-invoices).

## Звірка з DigiKey

**«🔍 Звірити з DigiKey»** — порівнює замовлення на DigiKey з базою Minerva: оновлює адресу, дати, статус,
кур'єра, трекінг, ціни й додає замовлення, яких не було. Виберіть глибину (30 днів, 90 днів, 1 рік, 2 роки, усі) →
**«🔍 Перегляд (без змін)»** → перегляньте звіт («Оновлені поля»: було → стало, SKU без товару, помилки) →
**«✅ Застосувати зміни»**.

Звідти ж — [📦 Перенести трекінги недоставлених замовлень у відправлення](/bots/push-tracking/): відправлені
замовлення з трек-номером без запису в Доставці → **«📦 Перенести всі у відправлення»**.

## Повідомлення покупців (💬 Messages Hub)

[💬 DigiKey Messages Hub](/admin/bots/digikeyconfig/messages/) — листування з покупцями DigiKey: **«🔄 Оновити з
DigiKey»**, фільтр за номером замовлення, сортування **«🔴 Непрочитані»** / **«🕒 Нові → Старі ↓»**, відповідь
**«📤 Надіслати»**, AI-чернетка **«✨ Генерувати відповідь»** з інструкцією, переклад **«🌐 UA»**,
**«➕ Нова тема»**.

Повідомлення одного замовлення видно і в його картці — **«💬 Повідомлення DigiKey»** у панелі
**«🔧 DigiKey API Actions»**.

## Часті питання та проблеми

**«🔑 Потрібна авторизація» на сторінці замовлень.** Marketplace API потребує входу: **«🔑 Авторизувати DigiKey
Marketplace»** (сторінка 🛒 DigiKey → «🔐 Авторизація Marketplace»).

**«⚠️ Товари не знайдено в базі (N SKU)».** Supplier SKU замовлення не збігається з товаром складу — створіть
товар або прив'яжіть лістинг ([Лістинги](guide:digikey/listings)).

**Статус замовлення «стрибає» назад.** Статус з DigiKey ставиться лише вперед; якщо статус ведете ви чи трекінг
перевізника — вимкніть **«Оновлювати статус замовлення при синхронізації»**.

**Замовлення не з'являються.** Перевірте «Синхронізація увімкнена», «Sandbox режим» (має бути вимкнено) і
**«🔄 Синхронізувати»** вручну.
