## Що це

Перевірити API можна чотирма способами — від найпростішого:

| Спосіб | Коли |
|---|---|
| **Консоль API** в Minerva | швидко перевірити ключ чи запит, нічого не встановлюючи |
| **API-тестер** (HTML-файл) | інтегратор перевіряє з свого комп'ютера, кнопками |
| **Скрипти Python** | пройти цілий сценарій (магазин, закупівлі) або прийняти вебхуки |
| **curl** | приклади з [Усі адреси API](guide:api/endpoints) |

## Консоль API

[🖥 Консоль API](/dashboard/api/console/) — лише для **адміністратора Minerva** (суперкористувач або роль
адміністратора); іншим співробітникам сторінка відповідає «доступ заборонено», а кнопок консолі вони не бачать.
Ліворуч запит, праворуч відповідь.

Консоль надсилає запити **лише до API цієї Minerva** (`/api/v1/…` на тій самій адресі, з якої її відкрито).
Інші сайти, зовнішні API (DHL, DigiKey, Jumingo) і адреси внутрішньої мережі вона не відкриває — їх перевіряють
кнопки на сторінках перевізників і DigiKey.

1. **«Пресети»** — готові запити до Minerva: **«🔌 Ping»**, **«🏬 Залишки»**, **«🛒 Перевірка кошика»**,
   **«📥 Прихід»**, **«🧾 Нове замовлення»**, **«🚚 Відправлення»**, **«🏠 Minerva Orders»**,
   **«📦 Minerva Products»**; закупівлі CRM — **«📦 Закупівля CRM»**, **«🚛 Трек закупівлі»**, **«✅ Доставлено»**,
   **«📋 Очікуються»** (номер `B-TEST-1`).
2. Пресет заповнює **«Метод та URL»**, **«Авторизація»**, **«Заголовки (Headers)»** і **«Тіло запиту (Body)»**.
   Авторизація **«🔑 Ключ Minerva (сервер підставить)»** — список активних ключів з
   [🔑 API Токени](/admin/api/apikey/): назва й замаскований ключ (`abcd••••••••wxyz`). Повний ключ у браузер не
   потрапляє — сервер сам додає його до запиту. **«Token вручну»** — вставити ключ самому.
3. Замініть у тілі тестовий артикул на свій (напр. `FT220407`).
4. **«▶ Надіслати запит»** (або Ctrl+Enter у полі адреси).
5. Праворуч — код відповіді, час і вкладки **«Body»**, **«Headers»**, **«Запит»**, **«Історія»** (останні
   запити зберігаються у вашому браузері).

Швидкий старт з інших сторінок: у картці ключа (**«Технічна інформація»**) — посилання **«Консоль API»**, у
[📖 Документація API](/dashboard/api/docs/) — **«🖥 Консоль (Ping)»** (консоль з пресетом Ping) і
**«🖥 Консоль (закупівля CRM)»** (з пресетом закупівлі).

> ⚠️ Консоль виконує **справжні** запити: «Нове замовлення» створює замовлення, «Прихід» змінює склад. Тестуйте на
> тестовому товарі й потім приберіть тестові записи.

> ℹ️ Запит виконує сам сервер Minerva, але з вашою IP-адресою: ключ з **«Дозволеними IP-адресами»** працює в
> консолі, якщо ваш комп'ютер серед дозволених. Запит видно в [📜 Журнал API](/admin/api/apirequestlog/).

## API-тестер у браузері

Для інтегратора, який не має доступу до адмінки Minerva:

1. [📖 Документація API](/dashboard/api/docs/) → **«🧪 Завантажити API-тестер (HTML)»** (або на
   [🔌 API Інтеграції](/dashboard/api/) — **«🧪 Завантажити API-тестер»**). Передайте файл інтегратору.
2. Відкрити файл подвійним кліком, вписати адресу Minerva (`{{base_url}}`) і ключ.
3. Кнопки самі формують запит і пояснюють відповідь:
   - **«🔌 Перевірити підключення»**;
   - склад: **«🏬 Залишки»**, **«📦 Один товар»**, **«✅ В наявності»**, **«⚠️ Мало на складі»**,
     **«🛒 Перевірка кошика»**, **«📜 Рухи товару»**, **«📍 Локації»**, **«📥 Прихід»**;
   - замовлення: **«🧾 Останні замовлення»**, **«🔎 Знайти за номером»**, **«📄 Деталі за ID»**,
     **«🚚 Відправлення / трекінг»**, **«➕ Створити тестове замовлення»**, **«✖ Скасувати за ID»**;
   - закупівлі з CRM: **«📋 Ще очікуються»**, **«📦 Передати замовлення»**, **«🚛 Трек-номер»**, **«✅ Доставлено»**
     (вдруге — `duplicate`), **«✖ Скасувати»**;
   - **«Довільний запит»** → **«▶ Надіслати»**; **«📋 Копіювати відповідь»**; історія запитів.

Тестер працює з будь-якого комп'ютера: API дозволяє виклики з браузера, коли ключ передано в заголовку.

## Скрипти Python

Завантажити — кнопки на [📖 Документація API](/dashboard/api/docs/). Потрібен лише пакет `requests`. Адреса й
ключ — у змінних оточення:

```bash
export MINERVA_URL={{base_url}}
export MINERVA_TOKEN=…            # PowerShell: $env:MINERVA_TOKEN="…"
```

| Скрипт | Що робить | Приклади |
|---|---|---|
| **shop_client.py** | сценарії магазину | `python shop_client.py ping` · `stock FT220407` · `check FT220407:2` · `order FT220407:1` · `track WS-1001` · `sync` |
| **crm_purchases.py** | закупівлі з CRM | `python crm_purchases.py demo FT220407` — увесь цикл з поясненнями |
| **webhook_receiver.py** | приймає вебхуки й перевіряє підпис | `python webhook_receiver.py` — слухає порт 9000 |

Тест вебхуків локально: запустіть `webhook_receiver.py` з `WEBHOOK_SECRET=<секрет вебхука>`, у Minerva створіть
вебхук на `http://<IP вашого ПК>:9000/` і надішліть **«📡 Надіслати тестову подію (ping)»** ([Вебхуки](guide:api/webhooks)).
Для CRM — подія `purchase_order.updated` і `OWN_SOURCE=crm`.

## curl

```bash
curl -H "Authorization: Token $MINERVA_KEY" {{base_url}}/api/v1/ping/
curl -H "Authorization: Token $MINERVA_KEY" "{{base_url}}/api/v1/stock/?in_stock=true"
curl -X POST "{{base_url}}/api/v1/stock/check/" -H "Authorization: Token $MINERVA_KEY" \
     -H "Content-Type: application/json" -d '{"items":[{"sku":"FT220407","qty":2}]}'
```

У Windows PowerShell пишіть `curl.exe` замість `curl`.

## Що сталося — журнал

Кожен запит будь-яким способом видно в [📜 Журнал API](/admin/api/apirequestlog/): ключ, IP, адреса, код
відповіді, які артикули, скільки тривав ([Ключі API](guide:api/keys)). Вебхуки — у
[📋 Журнал вебхуків](/admin/api/webhookdelivery/).

## Чекліст перед запуском магазину (~15 хв)

1. Створити ключ `webshop-test` з потрібними правами і джерелом замовлень `webshop-test`.
2. **«🔌 Ping»** — у відповіді назва ключа й права.
3. **«🏬 Залишки»** — запам'ятати `available` тестового товару.
4. **«📥 Прихід»** на 10 шт — `available_after` +10; той самий запит ще раз (той самий `external_key`) — `200`,
   залишок не змінився.
5. **«🛒 Перевірка кошика»** з кількістю більшою за залишок — `ok: false`.
6. **«🧾 Нове замовлення»** — `201`, `created: true`; замовлення в Minerva, клієнт у CRM, залишок менший.
   Те саме ще раз — `200`, `created: false`.
7. Замовлення з неіснуючим артикулом — `400 invalid_lines`.
8. `POST /orders/{id}/cancel/` — `cancelled`, залишок повернувся.
9. Вебхук на приймач → прихід → подія `stock.changed` у приймачі. Вимкнути приймач, зробити прихід — у журналі
   вебхуків «Очікує»; увімкнути — за 1–5 хв «Доставлено».
10. Прибрати тестові замовлення, вимкнути тестовий ключ і вебхук.
