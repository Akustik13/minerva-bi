## Що це

**MCP** (Model Context Protocol) — спосіб, яким агенти на кшталт **Claude Code** чи **Claude Desktop** працюють з
чужими програмами. Minerva дає їм ті самі інструменти, що й [🧩 Завданням агенту](guide:inventory/agent-tasks):

- **читати** — усі розділи Minerva, на які в людини ключа є право: пошта й календар (лише свої), продажі й аналітика,
  CRM, склад, закупівлі, відправлення й перевізники, інтернет-магазини, DigiKey (лістинги, ціни, повідомлення покупців),
  Angebote, проєкти, постачальники й [запити їм (RFQ)](guide:inventory/supplier-requests) — отримувачі, пропозиції,
  порівняння, файли, листування (лише своє), робочий час askDANTE (лише свій), а ще **пошук по всіх даташитах у RAG**;
- **пропонувати** — лист чи відповідь, нотатку клієнту, момент проєкту, час в askDANTE, відповідь покупцю DigiKey,
  зміну в картці товару, прихід, новий товар, подію в календарі, показ / ціну в магазині, ціни чи строк на DigiKey,
  чернетку відправлення чи Angebot, закупівлю, трек-номер чи статус замовлення; у запитах постачальникам — новий
  запит, кому ще надіслати, пропозицію постачальника з його листа, стан, рішення (🏆 / ✅ / ✖), закриття,
  надсилання й нагадування, відповідь постачальнику, чернетку закупівлі.

Сам агент **нічого не змінює й не надсилає**: кожна пропозиція потрапляє в «🧩 Завдання агенту» людини ключа й чекає
її ✓ — так само, як пропозиції агента Minerva. Лист іде лише тоді, коли ви натиснете «✉️ Надіслати» (або відкриєте
чернетку).

> 🔒 **Ваша пошта, календар і робочий час** — лише через [особистий ключ](guide:api/keys) («🔒 Лише я»), де агент —
> ви самі. Через спільний ключ агент їх не бачить, а в хронології клієнта й проєктах замість теми листа — «лист з
> іншої скриньки».

> ℹ️ Історії листування з RAG і пошуку в інтернеті через MCP немає. Історію з RAG шукає лише агент
> [🧩 Завдань агенту](guide:inventory/agent-tasks).

## Як підключити

### 1. Ключ API

У [🔑 API ключах](/admin/api/apikey/add/) створіть окремий ключ, напр. «Claude Code — Anna»:

| Поле | Що вписати |
|---|---|
| Права | `agent:read` — лише читання; `agent:write` — ще й пропозиції |
| **🤖 Агент (MCP) — від імені кого** | людина, яка перевірятиме пропозиції (у неї має бути розділ «🤖 Агент») |
| **🔒 Лише я (особистий ключ)** | поставте, якщо ключ лише ваш і агент — ви: тоді агенту доступні ваша пошта, календар і робочий час, а повний ключ бачите лише ви |
| Магазин | порожньо — ключ сайту магазину для MCP не підходить |

Обмеження (IP, ліміти) і [журнал запитів](guide:api/keys) діють, як для будь-якого ключа.

### 2. Claude Code

У терміналі (адресу й ключ підставте свої):

```bash
claude mcp add --transport http minerva {{base_url}}/api/v1/mcp/ --header "Authorization: Bearer <ключ>"
```

Перевірка — команда `/mcp` у Claude Code: «minerva · connected» і список інструментів.

### 3. Claude Desktop

Claude Desktop підключається через `mcp-remote` (потрібен Node.js). **Settings → Developer → Edit Config**, у файл
`claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "minerva": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{base_url}}/api/v1/mcp/", "--header", "Authorization:${MINERVA_AUTH}"],
      "env": {"MINERVA_AUTH": "Bearer <ключ>"}
    }
  }
}
```

Перезапустіть Claude Desktop — у чаті з'явиться значок інструментів «minerva».

> ⚠️ Ключ — як пароль: не публікуйте файл налаштувань і не пересилайте ключ у чатах.

## Як працювати

Пишіть агенту своїми словами, напр. в Claude Code:

- «Знайди в Minerva антени AN2202…, прочитай даташити й запропонуй вагу однієї штуки та країну виробника».
- «Які товари категорії Filter не показані в магазині sevskiy? Запропонуй показати ті, що є на складі».
- «Перевір ціни на DigiKey для FT220407 — чи вони за правилами Minerva?»
- «Які антени в наших даташитах працюють на 5,8 ГГц? Яких із них ще немає в Minerva?»
- «Що прийшло сьогодні в пошту від клієнтів? Підготуй відповіді на запити цін».
- «Покажи продажі за жовтень по джерелах і порівняй з вереснем; хто з клієнтів купив найбільше?»
- «Що відкритого по проєкту P-2026-014? Додай момент “клієнт затвердив макет” з листа від 12.11».
- «Які нові повідомлення покупців DigiKey? Підготуй відповідь на питання про строк поставки».
- «Запиши в askDANTE 1,5 год на проєкт DigiKey за вчора — опис з моїх листів».
- «Проаналізуй RFQ-2026-003: прочитай усі відповіді постачальників і їхні вкладення, внеси ціни в таблицю, порівняй
  для кожної кількості з разовими витратами й строками і запиши пораду в запит».
- «Нагадай тим, хто не відповів на RFQ-2026-005, і додай до запиту ще двох виробників плат із категорії».

## Часті питання та проблеми

**401 Unauthorized.** Ключа немає в заголовку або він неправильний: `Authorization: Bearer <ключ>` (працює й
`Token <ключ>`).

**403 «У ключа не вказано «🤖 Агент (MCP) — від імені кого»».** Заповніть це поле в картці ключа.

**403 на пропозиції, а читання працює.** У ключа лише `agent:read` — додайте `agent:write`.

**Агент не бачить запитів постачальникам (RFQ).** Людині ключа потрібне право на «📨 Запити постачальникам» (розділ «Постачальники»); пропозиції — з правом змінювати запити, чернетка закупівлі — ще й створювати закупівлі. Листування з постачальником — лише через 🔒 особистий ключ.

**403 «Людина ключа не має права на завдання агенту».** Її ролі бракує розділу «🤖 Агент» — див.
[👁 Як бачить Minerva](/admin/core/userprofile/).

**Агент каже «запропоновано», а в картці товару нічого не змінилось.** Так і має бути — відкрийте
[🧩 Завдання агенту](/admin/agent/agenttask/) і застосуйте ✓.

**Немає `search_datasheets` у списку інструментів.** Помічник по продукції не налаштований чи вимкнений, або людині
ключа бракує права «📦 Помічник по продукції» — див. [🔐 Доступ до бази знань і RAG](guide:ai/knowledge-access).
«RAG зараз зайнятий» — він обробляє інший запит, спробуйте трохи пізніше.

**Немає `search_mail`, `calendar_events` чи `my_worktime`.** Ключ спільний або «🤖 Агент (MCP)» — не власник
ключа. Створіть [особистий ключ](guide:api/keys) («🔒 Лише я») і вкажіть агентом себе. Для робочого часу ще потрібен
ваш працівник askDANTE у Minerva.

**Лист на чужу адресу?** Адресатів обирає агент, тому на сторінці перевірки над листом — «⚠️ адресатів обрав
зовнішній агент». Перевірте «Кому» перед «✉️ Надіслати».

**Хто що робив?** Кожен виклик — у «Кроках агента» на сторінці завдання і в журналі запитів ключа.
