## Що це

Пошту Minerva можна розкласти так, як вам звично: як в Outlook, Gmail чи Thunderbird, або зібрати свій
варіант. Усі налаштування на цій сторінці — **лише для вас**, колеги бачать пошту по-своєму. Зміни видно
одразу, без перезавантаження.

## 🎨 Вигляд пошти

1. Відкрийте [📥 Вхідні](/email/) і натисніть **🎨** над списком листів (або вкладка **«⋯ Ще»** →
   **«🎨 Вигляд пошти…»**).
2. Виберіть готовий шаблон (під кожним — маленька схема) — таблиця **«Шаблони»** нижче.
3. Або змініть окремі перемикачі під шаблонами — шаблон стане **«✏️ Свій»** (таблиця **«Перемикачі»**).
4. **«Готово»**. **«↺ Як за замовчуванням»** — повернути «🏛 Minerva».

### Шаблони

| Шаблон | Як виглядає |
|---|---|
| **🏛 Minerva** | вкладки внизу лівої колонки, лист праворуч (за замовчуванням) |
| **🗂 Як раніше** | папки, категорії, проєкти й клієнти підряд в одній колонці, розділи згортаються |
| **📘 Outlook** | значки розділів збоку, вкладення над текстом листа, назви файлів у списку |
| **✉️ Gmail** | широкий список на весь екран, лист відкривається замість нього (← назад), файли в рядку |
| **🦅 Thunderbird** | список угорі, лист під ним, щільні рядки без тексту |
| **💻 Ноутбук** | найбільше листів на маленькому екрані: значки збоку, щільно, без міток |

### Перемикачі

| Перемикач | Варіанти |
|---|---|
| **«Ліва колонка»** | ▁ Вкладки внизу · ▌ Значки збоку · ☰ Усе підряд |
| **«Відкритий лист»** | ▐ Праворуч · ▄ Під списком · ⛶ Замість списку |
| **«Рядки списку»** | Щільно · Звичайно · Просторо |
| **«Текст листа в списку»** | Без тексту · 1 рядок · 2 рядки |
| **«Кружок відправника»** | Показувати · Ні |
| **«Мітки: категорія, клієнт, проєкт»** | Показувати · Ні |
| **«Назви вкладень у списку»** | Ні · 📎 Показувати |
| **«Вкладення у відкритому листі»** | Під текстом · Над текстом |
| **«Гарячі клавіші»** | Увімкнено · Вимкнено |

Підказки:

- **⬒** над списком — швидко перемкнути лист **праворуч ↔ під списком**. Коли лист під списком, висоту
  списку можна тягнути мишкою.
- **«⛶ Замість списку»** (як Gmail): клік відкриває лист на всю ширину; назад — **«← До списку»**, **Esc**
  або **u**.
- Ширину колонок теж можна тягнути; **«⋯ Ще» → «↺ Скинути розміри»** — повернути. **◀** угорі лівої колонки
  — сховати її зовсім (**▶** — показати).
- На вузькому екрані (до 1200 px) список листів згортається сам, коли відкрито лист праворуч.

## ⌨ Гарячі клавіші

Як у Gmail. Діють, коли курсор не в полі вводу (і коли ви клікнули в текст листа). Підказка — **?** або
**«⋯ Ще» → «⌨ Гарячі клавіші»**.

| Клавіша | Дія |
|---|---|
| **j** / **k** | наступний / попередній лист |
| **Enter** / **o** | відкрити лист |
| **Esc** / **u** | назад до списку (у вигляді «Замість списку») |
| **r** / **f** | відповісти / переслати |
| **e** | в архів |
| **#** / **Delete** | видалити |
| **!** | спам |
| **s** | важливий ⭐ |
| **Shift+I** / **Shift+U** | прочитано / непрочитано |
| **x** | вибрати лист (для масових дій) |
| **c** | новий лист |
| **/** | пошук (поле фільтра над списком) |
| **?** | підказка з клавішами |

Після видалення, архіву чи спаму Minerva переходить до наступного листа. Вимкнути клавіші — перемикач
**«Гарячі клавіші»** у **🎨 Вигляді пошти**.

## Меню правого кліку — під себе

1. Правий клік на будь-якому листі → унизу меню **«⚙ Налаштувати це меню…»**.
2. Таблиця **«⚙ Меню правого кліку на листі»**: **«Пункт»**, **«У списку листів»**, **«У відкритому
   листі»**. Галочка — пункт у меню; без галочки — сховано в **«⋯ Ще»** внизу меню.
3. **«💾 Зберегти»** або **«↺ Як за замовчуванням»**.

За замовчуванням у **«⋯ Ще»** сховано: у списку — «Відкрити окремо», «Значок відправника», пункти бази знань,
«Правило з відправника», «Завдання в календар»; у відкритому листі — ще й «Перекласти лист», «Важливе»,
«Спам», «Архів». Усі пункти меню описані в [Скриньці](guide:mail/inbox).

**Shift + правий клік** — звичайне меню браузера (наприклад, щоб скопіювати посилання).

## Ліва колонка

- **«⋯ Ще»** → **«Значки категорій і проєктів»** — емодзі перед назвами своїх категорій і проєктів у
  колонці й мітках.
- Правий клік на проєкті → **«🔢 Ховати номер P-… перед назвою»** / **«🔢 Показувати номер P-… перед
  назвою»**; там же **«🎨 Значок…»** проєкту.
- Порядок і **⭐ Обране** в розділі «🏷 Категорії» — [Скринька](guide:mail/inbox).
- [Налаштування Email асистента](/admin/email_assistant/emailsettings/) → **«Показувати панель навігації
  Minerva»** — ліве меню Minerva на сторінках пошти (вимкніть, щоб пошті було просторіше).

## Логотипи відправників

Перемикач **«⋯ Ще» → «Логотипи відправників»** (увімкнено): замість першої букви в кружку — значок сайту
компанії відправника. Minerva бере його сама з сайту домену відправника, один раз на домен, без сторонніх
сервісів. Для Gmail, GMX та інших поштових сервісів логотипа немає — лишається буква.

### Свій значок відправника

Логотип не знайшовся або не подобається:

1. Правий клік на листі → **«🖼 Значок відправника…»** (за замовчуванням — у **«⋯ Ще»** внизу меню; пункт є,
   коли ввімкнено **«Логотипи відправників»**).
2. **«Для кого»**: ця адреса або **«весь домен»**.
3. Вкладка **«😀 Стандартний значок»** — клік на емодзі й колір фону (або **«або свій емодзі»**).
4. Або вкладка **«🖼 Своє зображення»**: перетягніть картинку, вставте з буфера (**Ctrl+V**),
   **«📂 Вибрати файл…»** або **«✏️ Підправити поточний значок»**. Далі:
   - тягніть зображення в колі, коліщатко миші — збільшити, подвійний клік — вписати / заповнити, стрілки —
     точно;
   - **«⤢ Вписати»** (усе в колі) / **«⬛ Заповнити коло»**, **«⟳ 90°»**, **«📂 Інший файл»**;
   - **«Фон»**: прозорий, 🎯 як у кутку зображення, готові кольори або свій.
5. Праворуч — **«Як виглядатиме»**: у списку, у відкритому листі й великим.
6. **«✓ Поставити значок»**. Інші кнопки: **«🔤 Буква замість логотипа»**, **«↺ Автоматично (логотип
   сайту)»**.

> ℹ️ Свій значок бачать **усі** користувачі Minerva. Формати — PNG, JPG, GIF, WEBP, ICO, BMP, SVG; великий
> файл Minerva зменшить сама.

## Часті питання та проблеми

**Клавіші не працюють** — курсор стоїть у полі (пошук, відповідь) — клікніть у список; або клавіші вимкнено в
**🎨 Вигляді пошти**.

**Зник список листів** — вибрано **«⛶ Замість списку»** і відкрито лист: **Esc** або **«← До списку»**. Або
список згорнуто кнопкою **◀** — натисніть її ще раз.

**Хочу як було до нових вкладок** — шаблон **«🗂 Як раніше»**.

**У відправника неправильний логотип** — **«🖼 Значок відправника…»** → **«🔤 Буква замість логотипа»** або
свій значок.
