## Що це

Для кожного товару, який показується хоча б в одному магазині, Minerva підбирає **фото** і **даташит** для сайту
в такому порядку:

1. **посилання з картки товару** — «Зображення (URL)», «Посилання на Datasheet»;
2. якщо посилання не відповідає або віддає не фото / не PDF — **файл, завантажений у картку** товару;
3. немає й його — сайт показує **свій файл**, як раніше.

Minerva перевіряє **вміст** (за першими байтами, а не за назвою): посилання `…/download.php?file=X.pdf` підходить, а
сторінка помилки з HTML — ні. Перевірену копію Minerva зберігає в себе; сайт забирає її у свій кеш і віддає
відвідувачам зі свого сервера (швидко, і політика безпеки сайту не дозволяє картинки з чужих адрес).

Звідки беруться посилання й файли в картках — [Фото й даташити товарів](guide:inventory/media).

## Як запустити

1. Відкрийте [🖼 Фото й даташити](/admin/shop/productmedia/). Угорі — панель **«🖼 Фото й даташити для сайту»**.
2. Натисніть **«🔄 Індексувати нові й змінені»** — ще не перевірені, змінені в картці та давно не перевірені
   посилання. **«🔁 Перевірити все заново»** — кожне посилання й файл (довше).
   Поле **«для:»** — усіх магазинів або лише товари одного магазину (про нові файли дізнається тільки його сайт).
3. Поки йде індексація — живий прогрес: «⏳ Перевірка N з M · поточний товар · ще ≈ X хв». Після завершення
   таблиця оновиться сама.
4. Перегляньте результат (поки вимкнено, сайт показує лише свої файли — нічого не зламається).
5. Натисніть **«▶ Увімкнути для сайту»** — сайт почне забирати перевірені копії.

Після ввімкнення Minerva сама перевіряє нові й змінені кожні 5 хвилин. **«Повторно перевіряти посилання:»** —
кожні N днів (вміст за посиланням може змінитися без зміни адреси) або «ні, лише нові й змінені».

## Панель і окремі сайти

Панель показує: **«Товарів у магазинах»**, для фото й даташитів окремо — ✅ готово, ⚠ посилання недоступне →
файл, ⚠ остання перевірена копія, — у Minerva немає, ❌ недоступно, ⏳ не перевірено, джерело (посилання / файл).

Для кожного магазину — рядок 🏬: «на сайті N з M», помилки, коли сайт звітував, і кнопки:

- **«▶ Забрати на сайт зараз»** — сайт отримає запит забрати нові файли, не чекаючи (стан оновиться за хвилину);
- **«⏸ Вимкнути для цього сайту»** / **«▶ Увімкнути для цього сайту»** — окремо для одного магазину (напр. тестовий
  сайт уже бере файли з Minerva, а справжній ще ні).

**«⏸ Вимкнути для сайту»** вимикає все одразу — сайти знову показують лише власні файли.

## Список

Рядок — товар × вид (🖼 Фото / 📄 Даташит). Колонки: **«Товар»**, тип, **«Стан»**, **«Розмір»**, перевірено,
**«На сайті»**, **«Помилка»**.

| Стан | Що означає |
|---|---|
| ✅ з посилання / ✅ файл Minerva | готово, сайт отримує копію |
| ⚠ посилання недоступне → файл Minerva | посилання не працює, взято файл з картки |
| ⚠ зараз недоступно → остання перевірена копія | джерело тимчасово не відповідає, але в картці нічого не змінювали — сайт і далі отримує попередню копію |
| — у Minerva немає → сайт показує свій файл | ні посилання, ні файлу |
| ❌ недоступно → сайт показує свій файл | посилання й файл не підходять (причина в «Помилка», напр. «сервер повернув HTML-сторінку») |
| ⏳ чекає перевірки | ще не перевірено |

Фільтри: **«Магазин»**, **«На сайті магазину»** (✅ сайт забрав / ⏳ ще не забрав / ❌ не вдалося завантажити /
— сайту нічого віддавати), тип, стан, звідки взято, остання придатна копія. Дія над вибраними —
**«🔄 Перевірити вибрані зараз»**.

## У картці товару й списках

- картка товару → блок **«🔗 Медіа та документи»** → **«🖼 Для сайту»**: що взято, звідки, помилки, чи вже на
  сайті кожного магазину, **«🔄 Перевірити зараз»** (спершу «Зберегти» картку) і **«усі фото й даташити →»**;
- [💶 Асортимент і ціни](/admin/shop/shoplisting/), колонка 🖼: мініатюра, 📄 і 🌐✓ — сайт цього магазину вже показує
  файли з Minerva, 🌐⏳ — ще не забрав;
- фільтр **«Фото / даташит»** у товарах і асортименті: без фото, без даташита, **«❌ Посилання не відповідає
  (перевірка для сайту)»**.

## Часті питання та проблеми

**«Індексацію перервано (перезапуск сервера?)»** — уже перевірене збережено, запустіть ще раз.

**«Уже йде інша індексація — дочекайтесь її завершення.»** — одночасно йде лише одна індексація.

**Сайт ще не звітував.** Натисніть «▶ Забрати на сайт зараз». У картці магазину має бути задана «Адреса сайту» —
інакше «у картці магазину не задано адресу сайту».

**Змінили фото в картці, а на сайті старе.** Після «Зберегти» товар перевіриться автоматично протягом 5 хвилин
(або «🔄 Перевірити зараз» у картці); потім сайт забирає нову копію.
