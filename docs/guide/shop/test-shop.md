## Що це

- **Копія магазину** — новий магазин з усіма налаштуваннями наявного, **крім ключів і секретів**. Так за хвилину
  готується магазин для нового сайту або тестової копії сайту.
- **Тестовий магазин** — магазин з галочкою **«🧪 Тестовий магазин»**: окрема нумерація `TEST-…`, справжні
  номери й Kundennummern не витрачаються, а замовлення за замовчуванням не чіпають склад і статистику.

> 💡 Для тестового сайту (напр. `test.shop.example.com`) завжди робіть **окремий магазин** і підключайте його
> своїм кодом. Якщо тестовий сайт працює ключем справжнього магазину, у них спільні акаунти покупців, кошики й
> замовлення — дорожня карта попередить «Ключем цього магазину користується ще …».

## Як скопіювати магазин

1. Відкрийте магазин у [🏬 Магазини](/admin/shop/shop/) → угорі справа **«📋 Копіювати магазин»** (або в списку
   позначте один магазин → дія **«📋 Копіювати магазин (без ключів)»**).
2. На сторінці **«Копіювати «…»»** заповніть:
   - **«Назва нового магазину»** (запропоновано «… (копія)»);
   - **«Код (джерело замовлень)»** — новий, напр. `webshop-test`; такий самий, як у наявного, не можна;
   - **«Адреса сайту»** — можна пізніше;
   - що копіювати: **«Асортимент і ціни (зі ступенями)»**, **«Зони доставки»**, **«Шаблони листів покупцям»**.
3. Поруч (на телефоні — нижче) видно, що саме буде скопійовано (кількість товарів, ступенів, зон, шаблонів) і що ні.
4. **«📋 Створити копію»** — відкриється картка нової копії.

| ✅ Копіюється | ⛔ Не копіюється |
|---|---|
| валюта, доставка й безкоштовна доставка, кабінет покупця й пошта, способи оплати, помічник (без ключа), пошук, нотатки | ключі Stripe і ключ помічника — введіть нові |
| асортимент з цінами й ступенями | ключі API сайту — сайт отримає свій при підключенні кодом |
| зони доставки (країни, ціни, терміни, винятки) | покупці, замовлення, оплати, звіти сайтів |
| шаблони листів | «За замовчуванням» і «Активний» — копія вимкнена |

## Що зробити в копії

Угорі картки копії — червоний банер **«Копія магазину «…»»** зі списком полів, які треба змінити (назва, код,
адреса сайту, назва для покупців, ключі, «Активний»). Ці поля підсвічені червоним; клік по назві в банері —
перехід до поля.

1. Змініть кожне підсвічене поле → **«Зберегти»** — підсвічування зникає, щойно поле змінено й збережено.
2. Якщо поле навмисно лишається таким самим — **«✓ Усе перевірено»** у банері.
3. Пройдіть [дорожню карту](guide:shop/overview) копії: доступ до адмінки сайту, підключення сайту кодом
   ([Адмінка сайту](guide:shop/site-admin)), перевірка зв'язку.
4. Коли все готово — увімкніть **«Активний»**.

У списку магазинів, доки поля не змінено, колонка **«Налаштування»** показує **«⚠ змінити: N»**.

## Тестовий магазин

Картка магазину, перший блок:

- **«🧪 Тестовий магазин»** — окрема нумерація: замовлення `TEST-PO-0001`, документи `TEST-OC-0001`,
  `TEST-CI-0001`, `TEST-PI-0001`, `TEST-PL-0001`, акаунти покупців `TEST-1`, `TEST-2`… Справжні номери й
  Kundennummern не витрачаються ([Kundennummer і номери документів](guide:shop/numbering));
- **«Тестові замовлення списують склад»** — вимкнено (за замовчуванням): замовлення тестового магазину не бронюють
  і не списують товар і не потрапляють у статистику продажів. Увімкніть, лише якщо хочете перевірити саме склад.

У списку магазинів тестовий магазин позначено 🧪.

**Фото й даташити окремо для тестового сайту:** на сторінці [🖼 Фото й даташити](/admin/shop/productmedia/) у
рядку магазину — **«▶ Увімкнути для цього сайту»** / **«⏸ Вимкнути для цього сайту»**, а індексацію можна
запустити лише для товарів одного магазину (поле **«для:»**). Так тестовий сайт бере файли з Minerva раніше за
справжній — [Фото й даташити](guide:shop/media).

**Перевірка тестового домену:** **«🔌 Перевірити зв'язок із сайтом»** бере адресу з поля «Адреса сайту», навіть
не збережену — можна перевірити тестовий домен, не змінюючи магазин.

## Приклад: новий сайт на тестовому домені

1. «Webshop» → **«📋 Копіювати магазин»** → назва «Webshop Test», код `webshop-test`, адреса
   `https://test.shop.example.com`.
2. У копії: **«🧪 Тестовий магазин»** увімкнено, **«Тестові замовлення списують склад»** вимкнено.
3. Внизу **«👥 Доступ до адмінки сайту»** — себе з роллю «Адміністратор сайту», **«Зберегти»**.
4. **«🔗 Підключити сайт (код)»** → код на тестовому сайті в `/admin/` → «🔌 Minerva».
5. **«Активний»** → **«Зберегти»** → **«🔌 Перевірити зв'язок із сайтом»**.
6. Тестове замовлення на сайті → у Продажах `TEST-PO-0001` з джерелом `webshop-test`, склад не змінено.

## Часті питання та проблеми

**«Такий код уже є — оберіть інший.»** — коди магазинів унікальні; додайте суфікс, напр. `-test`.

**Копія не приймає замовлень.** Копія створюється вимкненою й без ключа сайту — увімкніть «Активний» і підключіть
сайт кодом.

**Покупці зі справжнього сайту не можуть увійти на тестовому.** Так і має бути — акаунти належать магазину й не
копіюються.
