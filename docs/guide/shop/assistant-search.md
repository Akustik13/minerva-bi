## Що це

Дві функції сайту магазину, якими керують з картки магазину в Minerva:

- **🤖 Помічник Minerva на сайті** — кнопка «Minerva» на сайті: покупець ставить запитання, відповіді йдуть з
  даташитів і каталогу через наш RAG (той самий, що [помічник «Minerva» по продукції](guide:ai/product-assistant));
- **🔎 Пошук на сайті** — підказки під полем пошуку: розпізнавання частоти, роз'єму й стандарту в запиті, схожі
  товари, підходящі кабелі, «часто купують разом», а за бажанням — рекомендації AI.

Будь-який збій (немає ключа, RAG не відповідає, вичерпано ліміт) — сайт просто шукає й працює як звичайно.

## Помічник на сайті: як увімкнути

Картка магазину в [🏬 Магазини](/admin/shop/shop/) → блок **«🤖 Помічник Minerva на сайті»**:

1. **«Помічник на сайті»**:
   - **Як налаштовано на сайті (private/minerva-config.php)** — Minerva не втручається (старий спосіб);
   - **Увімкнено — кнопка «Minerva» на сайті**;
   - **Вимкнено — кнопки на сайті немає**.
2. **«Звідки відповіді»**:
   - **RAG API** — як «Помічник по продукції» Minerva: адреса й ключ беруться з
     [📚 Помічник по продукції](/admin/rag_assistant/ragsettings/), працює з будь-якого хостингу; поля нижче не
     потрібні;
   - **Веб-міст RAG** — **«Адреса помічника (RAG)»** і **«Ключ помічника»** нижче (або з файлу сайту); лише з
     локальної мережі. Адреса — `https://…` або `http://` лише до IP локальної мережі, напр. `http://192.168.2.68:8790`.
3. **«Ключ помічника»** — поле-пароль: збережений ключ не показується, порожнє поле його не змінює;
   **«Видалити збережений ключ помічника»** — прибрати.
4. **«Зберегти»**. Сайт перевіряє налаштування раз на хвилину.
5. **«🧪 Перевірити RAG»** (рядок **«Перевірка RAG»**) — Minerva сама звертається до RAG, яким користуються сайти.
   Із тестовим запитанням (напр. «Welche Antennen gibt es für 868 MHz?») чекає відповідь до 45 с.

Рядок **«Зараз»** показує налаштування Minerva й таблицю того, що фактично використовує кожен сайт:
**«Стан»** (кнопка є / кнопки немає), **«Звертається до»**, **«Адреса з»**, **«Ключ з»**,
**«private/minerva-config.php»** (чи є файл на сайті), **«Звіт»**.

**«🗑 Видалити private/minerva-config.php на сайтах»** — коли все керується з Minerva, старий файл з адресою й
ключем на сайтах можна прибрати: сайти видалять його протягом хвилини. Кнопка недоступна, якщо без файлу чат
зупиниться (вибрано «Як налаштовано на сайті» або веб-міст без адреси й ключа в Minerva).

## Підказки в пошуку: режими

Блок **«🔎 Пошук на сайті»** (згорнутий) → **«Підказки в пошуку на сайті»**:

| Режим | Що отримує покупець | Вартість |
|---|---|---|
| **Вимкнено — звичайний пошук** | лише результати | — |
| **Розумний пошук + підказки за правилами** | частота, роз'єм і стандарт у запиті, схожі товари, кабелі, наступник, «часто купують разом» | безкоштовно |
| **… + AI-підказки Claude** | ще до 3 рекомендацій моделі з каталогу магазину з поясненням | платно — ключ Anthropic у Minerva |
| **… + AI-підказки RAG** | рекомендації нашого RAG за даташитами (відповідь за 5–20 с) | платно лише з хмарною моделлю на RAG-ПК |
| **… + Claude і RAG разом** | обидва блоки — щоб порівняти | блок Claude платний завжди |

«Часто купують разом» — товари, які щонайменше двічі були в одному замовленні (за 3 роки), лише видимі в магазині.

Інші поля:

- **«AI-модель підказок»** — Claude Opus 5.5 (найкраща якість) / Sonnet 5.5 (швидше й дешевше) / Haiku 5.5
  (найшвидше й найдешевше);
- **«AI-підказок на добу (максимум)»** — 200 за замовчуванням, окремо для Claude і для RAG. Після ліміту до кінця
  доби сайт показує лише підказки за правилами. Повторні однакові запити — з кешу (доба), у ліміт не входять.

Ключ Anthropic для Claude — у [Налаштування AI](/admin/strategy/aisettings/) ([🏛 Minerva AI](guide:ai/minerva-ai)).
Адреса й ключ RAG — у [📚 Помічник по продукції](/admin/rag_assistant/ragsettings/).

На сайті підказки можна вимкнути окремо: `/admin/` сайту → «Магазин» → «Пошукові підказки». Кнопка «Frag Minerva →»
у підказках відкриває чат помічника з цим запитом.

## Стан і витрати

Рядок **«Стан і витрати»** в блоці «🔎 Пошук на сайті»:

- **«AI сьогодні: … з 200»** і **«AI загалом»** — виклики, з кешу, помилки, витрачено ≈ $ (за цінами Anthropic API
  для моделі, що відповіла, без ПДВ), токени. Точна сума — Claude Console → Usage / Cost;
- **«RAG сьогодні»** / **«RAG загалом»** — завдання, з кешу, «RAG зайнятий», зупинені покинуті, запасний пошук по
  даташитах, помилки. RAG-підказки токенів Anthropic не витрачають;
- рядок моделі RAG — чим RAG відповідав востаннє (помаранчевий — хмарна модель, платить ключ RAG);
  **«🔄 Запитати RAG-ПК, яка модель зараз»** і **«🖥 RAG-ПК: що зараз робить →»**;
- **«Шукали й не знайшли»** — найчастіші запити без результатів; **«🔎 Усі запити на сайті →»**.

Попередження **«⚠ AI: …»** / **«⚠ RAG: …»** пояснюють, чому підказки не працюють: «не задано ключ Anthropic
(Minerva AI → Налаштування)», немає кредитів API, «денний ліміт вичерпано», «не задано адресу або ключ RAG API»,
«RAG щойно не відповів — 5 хв пауза».

## Що шукають на сайті

[🔎 Пошук на сайті](/admin/shop/shopsearchquery/) — журнал запитів (лише текст запиту й лічильники, без даних
покупців): **«Запит»**, **«Магазин»**, **«Пошуків»**, **«Без результатів»**, **«Знайдено востаннє»**, **«Востаннє»**.
Фільтр **«Результати»** → **«Шукали й не знайшли»** — підказка, яких товарів чи слів бракує в каталозі.

## Часті питання та проблеми

**Кнопки «Minerva» на сайті немає.** Перевірте «Помічник на сайті» = «Увімкнено» і таблицю «Зараз»: у сайту має
бути адреса й ключ. Для «RAG API» адреса й ключ мають бути в «📚 Помічник по продукції».

**«Спершу задайте тут адресу й ключ помічника — інакше без файлу чат на сайті зупиниться».** Для веб-моста
заповніть «Адреса помічника (RAG)» і «Ключ помічника» перед видаленням файлу.

**AI-підказки не з'являються, у стані «немає кредитів API».** Поповніть рахунок у Claude Console; до першого
успішного запиту попередження лишається, сайт показує підказки за правилами.
