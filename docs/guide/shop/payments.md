## Що це

У касі сайту покупець вибирає спосіб оплати. Їх три:

| Спосіб | Що бачить покупець | Що робить Minerva |
|---|---|---|
| **Передоплата (Vorkasse, переказ)** | реквізити для переказу | замовлення чекає оплати |
| **Рахунок (Kauf auf Rechnung)** | оплата за рахунком | замовлення в роботі, оплату відмічаєте ви |
| **Онлайн через Stripe** | «Kreditkarte / Online (Stripe)» → сторінка Stripe Checkout | сама рахує суму, створює сторінку оплати й позначає замовлення **«Оплачено»** |

Суму для Stripe рахує **лише Minerva** (нетто + доставка + ПДВ за ставкою, яку визначив сайт). Ключі Stripe
зберігаються тільки в Minerva — сайт їх не знає.

## Як вибрати способи оплати

1. Відкрийте магазин у [🏬 Магазини](/admin/shop/shop/), блок **«💳 Способи оплати на сайті»**.
2. **«Показувати в касі»** — позначте способи.
3. **«Вибрано за замовчуванням»** — який спосіб буде вибраний першим (або «— перший зі списку —»).
4. **«Зберегти»**.

Minerva перевіряє вибір у кожному замовленні: вимкнений спосіб не приймається. Stripe можна позначити лише коли
збережено секретний ключ — інакше помилка «Для Stripe потрібен секретний ключ (блок «💳 Оплата Stripe»)».

> ℹ️ Банківські реквізити для передоплати й строк оплати рахунку задаються на самому сайті (його `/admin/`).

## Як підключити Stripe

Спершу — у **тестовому режимі**, гроші не списуються.

1. У Stripe (dashboard.stripe.com) → **Developers → API keys** скопіюйте **секретний** ключ `sk_test_…`
   (для роботи — `sk_live_…` або обмежений `rk_live_…` з правами Checkout Sessions — запис, Charges /
   PaymentIntents — читання). Публічний `pk_…` не підходить.
2. У картці магазину, блок **«💳 Оплата Stripe»**, вставте його в поле **«Stripe: секретний ключ»**.
   Поле — як пароль: збережений ключ не показується, видно лише замаскований початок і кінець; порожнє поле
   ключ не змінює.
3. **«Зберегти»**, потім **«🔌 Перевірити ключ Stripe»** — Minerva скаже, чи ключ працює.
4. У рядку **«Стан Stripe»** скопіюйте **«Адреса вебхука для Stripe»** — вона виглядає як
   `https://<адреса Minerva>/api/v1/payments/stripe/webhook/webshop/` (останнє — код магазину).
5. У Stripe → **Developers → Webhooks → Add endpoint** вставте цю адресу й виберіть події зі списку під нею:
   `checkout.session.completed`, `checkout.session.async_payment_succeeded`,
   `checkout.session.async_payment_failed`, `checkout.session.expired`, `charge.refunded`.
6. Відкрийте створений endpoint у Stripe → **Signing secret** (`whsec_…`) → вставте в
   **«Stripe: секрет вебхука»** → **«Зберегти»**.
7. У **«💳 Способи оплати на сайті»** позначте **«Онлайн через Stripe (картки, Apple / Google Pay, SEPA …)»**.
8. Зробіть тестове замовлення на сайті й оплатіть карткою `4242 4242 4242 4242` (будь-яка майбутня дата й CVC).

Які саме способи покаже сторінка Stripe (картки, Apple / Google Pay, SEPA, Klarna…), вмикається в Stripe →
**Settings → Payment methods**. Для бойового режиму замініть обидва ключі на live-ключі.

> ⚠️ Ключі Stripe вводьте **лише** в поля-паролі картки магазину. Не надсилайте їх поштою чи в чат.
> **«Видалити збережені ключі Stripe»** (галочка + «Зберегти») прибирає обидва ключі.

## Як Minerva дізнається про оплату

- **Вебхук** — Stripe одразу повідомляє Minerva; замовлення стає **«Оплачено»** (у полі «Статус оплати»), номер
  платежу записується в замовлення.
- **Автоперевірка** — поки вебхуків від Stripe немає, Minerva сама раз на **«Автоперевірка оплат, хв»** (15 за
  замовчуванням, 0 — вимкнено) питає Stripe про незавершені оплати за 14 днів. Щойно приходять вебхуки
  (за останні 7 днів), автоперевірка зупиняється сама.

Стан видно в рядку **«Перевірка оплат»**: «вебхук працює (остання подія …)» або «вебхуків від Stripe ще немає —
Minerva перевіряє незавершені оплати кожні 15 хв». Дорожня карта магазину показує крок «Оплата» з
попередженням, доки не задано секрет вебхука.

Після оплати покупець отримує лист **«Zahlung erhalten»** («Оплату отримано — покупцю»), команда — сповіщення
email / Telegram ([Пошта магазину](guide:shop/mail)). Скасував оплату — на сайті в касі, листі й кабінеті є
«Jetzt bezahlen».

## Список «💳 Онлайн-оплати»

[💳 Онлайн-оплати](/admin/shop/shoppayment/) — кожна спроба оплати: **«Створено»**, **«Замовлення»**,
**«Магазин»**, **«Сума»**, **«Статус»**, **«Бойовий режим»**, **«Оплачено»**, **«Stripe»** (**«відкрити ↗»** —
платіж у Stripe). Записи лише для перегляду — стан змінює Stripe.

| Статус | Що означає |
|---|---|
| Очікує оплати | сторінку оплати створено, покупець ще не заплатив |
| Обробляється (SEPA тощо) | оплата йде кілька днів |
| Оплачено | гроші отримано |
| Помилка оплати | оплата не пройшла |
| Сесія закінчилась | покупець не заплатив вчасно |
| Повернено | гроші повернено в Stripe |

Угорі — **«🔄 Перевірити незавершені оплати в Stripe»** і «Незавершених зараз: N». Дія над вибраними —
**«🔄 Оновити стан зі Stripe»**. Фільтри: статус, магазин, бойовий режим.

## Перевірити оплати одного клієнта

- картка клієнта в [👤 Клієнти](/admin/crm/customer/) — **«💳 Перевірити оплати»** (або дія **«💳 Перевірити оплати
  Stripe»** у списку клієнтів);
- картка акаунта в [👤 Акаунти покупців](/admin/shop/shopcustomer/) — **«🔄 Перевірити оплати клієнта»** у блоці
  «Замовлення і кошик» (або дія **«🔄 Перевірити оплати Stripe»**);
- картка магазину — **«🔄 Перевірити незавершені оплати зараз»** у блоці «💳 Оплата Stripe».

## Захист від подвійної оплати

- Поки попередня оплата **обробляється** (SEPA тощо), нову сторінку оплати не створити — сайт отримає
  «409 payment_processing», покупець — «оплата вже обробляється».
- Якщо SEPA не пройшла, а замовлення вже оплачено іншим способом, стан «Оплачено» лишається.
- Адреса повернення з оплати — лише на домен **«Адреса сайту»** магазину; без неї оплата не стартує
  («У магазині не вказано «Адреса сайту»»).

## Часті питання та проблеми

**«Потрібен секретний ключ sk_… або обмежений rk_…»** — вставлено публічний ключ `pk_…`. Візьміть секретний.

**Покупець заплатив, а замовлення не «Оплачено».** Натисніть **«🔄 Перевірити незавершені оплати зараз»**. Якщо
допомогло — вебхук не доходить: перевірте адресу endpoint у Stripe і секрет `whsec_…` у картці.

**Покупці не бачать Stripe у касі.** Спосіб не позначено в **«Показувати в касі»** або ключ не збережено (дорожня
карта: «Stripe вибрано, але ключ не задано»).

**Тестове замовлення оплачене тестовою карткою.** У тестовому режимі гроші не списуються; скасуйте замовлення в
Продажах.
