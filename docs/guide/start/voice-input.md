## Що це

У Minerva можна не друкувати, а **говорити**. Коли курсор стоїть у полі для тексту, у його куті з'являється
кругла кнопка **🎤**:

- відповідь на лист у пошті («Що відповісти?»), сам лист у «Написати», нотатки й коментарі;
- запитання до помічників (🏛 Minerva AI, «Minerva»), прохання до AI в проєкті («🧠 Що змінити в плані?»,
  «🧠 Аналіз ризиків», «📝 Про що йшла мова»);
- пошук у списках і довгі текстові поля в картках.

Короткі поля для номерів, кодів, адрес email, телефонів, цін і дат — без 🎤: там голос лише заважав би.

## Як диктувати

1. Клікніть у поле — курсор там, куди писати.
2. Натисніть **🎤** — кнопка стає червоною й «дихає», під полем — **«🎤 Слухаю…»** і те, що Minerva вже чує.
3. Говоріть звичайно, реченнями. Готовий шматок тексту з'являється там, де курсор. Можна посунути курсор і
   говорити далі — текст піде туди.
4. Ще раз **🎤** (або **Esc**) — стоп.

Розділові знаки — словами:

| Скажіть | Буде |
|---|---|
| «кома» | , |
| «крапка» | . (наступне слово — з великої літери) |
| «знак питання» / «знак оклику» | ? / ! |
| «двокрапка», «крапка з комою» | : / ; |
| «новий рядок» / «новий абзац» | перенос рядка / порожній рядок |

Те саме німецькою («Komma», «Punkt», «Fragezeichen», «neue Zeile»), англійською («comma», «period», «new line»),
польською й російською.

> 💡 Перше слово речення Minerva пише з великої літери, між шматками тексту ставить пробіл.

## Мова

Мова розпізнавання — як мова інтерфейсу Minerva. Іншу — **правий клік на 🎤** → українська, Deutsch, English,
Русский, Polski. Вибір запам'ятовується на цьому комп'ютері.

> ℹ️ У вікні (наприклад, «✏️ Редактор плану») правий клік на 🎤 просто перемикає мову по колу — назва мови
> з'являється під полем.

## Хто розпізнає голос і куди він іде

Розпізнає **браузер**, не Minerva:

- **Chrome** — сервіс Google, **Edge** — сервіс Microsoft, **Safari** — Apple. Звук іде до них, назад — лише
  текст; у Minerva зберігається тільки те, що з'явилось у полі й ви зберегли.
- Нові версії Chrome вміють розпізнавати **на самому комп'ютері**, якщо мовна модель уже завантажена. Тоді
  Minerva пише **«🔒 на цьому ПК»** — голос нікуди не йде.
- **Firefox** розпізнавати голос не вміє — 🎤 там немає.

> ⚠️ Не диктуйте паролі, номери карток і подібне.

Альтернатива для будь-якої програми Windows — **Win + H** (голосове введення Windows): працює й у полях Minerva.

## Вимкнути

**«Мої налаштування»** → блок **«♿ Доступність»** → **«🎤 Голосовий набір»** → **«Ні — без 🎤»** →
**«💾 Зберегти налаштування»**. Діє на всіх ваших пристроях.

## Часті питання та проблеми

**🎤 не з'являється** — курсор має стояти в полі для тексту (не для номера чи дати); браузер — Chrome, Edge чи
Safari; у «Моїх налаштуваннях» голосовий набір не вимкнено.

**«Браузер не дозволив мікрофон»** — клікніть значок 🔒 (або 🎤) ліворуч від адреси сайту → **Мікрофон** →
**Дозволити**, оновіть сторінку й натисніть 🎤 ще раз.

**«Мікрофон не знайдено»** — під'єднайте гарнітуру чи мікрофон; у Windows — **Параметри → Система → Звук →
Вхід**, виберіть пристрій.

**«Немає зв'язку із сервісом розпізнавання»** — браузер не дістає свій сервіс (Google / Microsoft). Перевірте
інтернет або спробуйте інший браузер.

**Розпізнає не тією мовою** — правий клік на 🎤 → потрібна мова.

**Запис сам зупинився** — після довгої паузи браузер зупиняється; Minerva вмикає його знову, поки курсор у полі.
Якщо 🎤 уже не червона — натисніть ще раз.
