Privacy notice — Minerva

Operator: {{ company_name }}{% if company_email %} · {{ company_email }}{% endif %} · Last updated {{ updated }}

Minerva is the internal business system of {{ company_name }}. It runs on the company's own server and is used only by the company's employees. This notice describes what Minerva does with data from Google Calendar and Microsoft Outlook calendars that an employee connects in Minerva («Calendars»).

What Minerva accesses

  • Google: your e-mail address (to show which account is connected) and your calendars and events (scope https://www.googleapis.com/auth/calendar).
  • Microsoft: your basic profile and your calendars and events (User.Read, Calendars.ReadWrite, offline_access).

How the data is used

  • To show your events in the Minerva calendar.
  • To copy events between Minerva, Google and Outlook according to rules that you create yourself (“from → to”), and to add an event to your calendar when you choose to (for example a deadline found in an e-mail). Minerva changes or deletes only events it created itself.
  • For Minerva features you start yourself, for example recording working time for a meeting. If you explicitly use an AI feature, the event titles needed for that request may be processed by the AI service the company uses for Minerva, only to answer that request.

Data from Google and Microsoft is not sold, not used for advertising and not passed on to third parties beyond what is described above. Minerva's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage

  • Access tokens and the events Minerva shows are stored only on the company's Minerva server.
  • Events are refreshed regularly; events that disappear from your calendar are removed from Minerva's copy.

Disconnecting

You can disconnect an account at any time in Minerva («Calendars» → disconnect). Minerva then deletes its access tokens, the list of your calendars and the rules for that account; copies that were already created remain where they are. You can also revoke access in your Google account or Microsoft account.

Datenschutzhinweis — Minerva

Betreiber: {{ company_name }}{% if company_email %} · {{ company_email }}{% endif %} · Stand {{ updated }}

Minerva ist das interne Geschäftssystem von {{ company_name }}. Es läuft auf dem eigenen Server des Unternehmens und wird nur von dessen Mitarbeitenden genutzt. Dieser Hinweis beschreibt, was Minerva mit Daten aus Google Kalender und Microsoft-Outlook-Kalendern macht, die Mitarbeitende in Minerva verbinden («Kalender»).

Worauf Minerva zugreift

  • Google: Ihre E-Mail-Adresse (um das verbundene Konto anzuzeigen) sowie Ihre Kalender und Termine (Bereich https://www.googleapis.com/auth/calendar).
  • Microsoft: Ihr Basisprofil sowie Ihre Kalender und Termine (User.Read, Calendars.ReadWrite, offline_access).

Wofür die Daten genutzt werden

  • Um Ihre Termine im Minerva-Kalender anzuzeigen.
  • Um Termine zwischen Minerva, Google und Outlook nach Regeln zu kopieren, die Sie selbst anlegen („von → nach“), und um einen Termin in Ihren Kalender einzutragen, wenn Sie das wählen (z. B. eine Frist aus einer E-Mail). Minerva ändert oder löscht nur Termine, die es selbst erstellt hat.
  • Für Minerva-Funktionen, die Sie selbst starten, z. B. die Erfassung von Arbeitszeit für einen Termin. Wenn Sie ausdrücklich eine KI-Funktion nutzen, können die dafür nötigen Terminbezeichnungen von dem KI-Dienst verarbeitet werden, den das Unternehmen für Minerva nutzt — nur zur Beantwortung dieser Anfrage.

Daten von Google und Microsoft werden nicht verkauft, nicht für Werbung genutzt und nicht über das Beschriebene hinaus an Dritte weitergegeben. Die Nutzung von Informationen aus Google-APIs durch Minerva entspricht der Google API Services User Data Policy, einschließlich der Limited-Use-Anforderungen.

Speicherung

  • Zugriffstoken und die von Minerva angezeigten Termine werden nur auf dem Minerva-Server des Unternehmens gespeichert.
  • Termine werden regelmäßig aktualisiert; Termine, die aus Ihrem Kalender verschwinden, werden aus der Kopie in Minerva entfernt.

Verbindung trennen

Sie können ein Konto jederzeit in Minerva trennen («Kalender» → trennen). Minerva löscht dann seine Zugriffstoken, die Liste Ihrer Kalender und die Regeln für dieses Konto; bereits erstellte Kopien bleiben, wo sie sind. Den Zugriff können Sie auch in Ihrem Google-Konto oder Microsoft-Konto widerrufen.
